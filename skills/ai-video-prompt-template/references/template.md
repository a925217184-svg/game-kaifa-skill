# AI 视频提示词模板（分镜脚本式 · 通用骨架版）

> **定位**：这是一套**纯结构模板**，不含任何固定风格。风格、题材、角色、光效全部由你每次填入。
> 符号约定：`【必填】`是每次必须填的；`〔可调〕`是可改可删的。
> 范文（巨蛇对战）只作为结构示范，不代表本模板的风格倾向。

---

## 第 0 步：设定卡（每次创作先填，全篇复用）

| 设定项 | 填什么 |
|---|---|
| 【主体角色】 | 名字/称号 + 外形关键特征（服装、武器、标志性配件） |
| 【对手/障碍】 | 形体定义 + 明确排除项（如"无四肢、无翅膀"或"纯机械、无生物特征"） |
| 【场景】 | 地点 + 天气/时段 + 地面材质与标志性物件 |
| 【核心光效/特效体系】 | 主角方颜色形态 vs 对方颜色形态（写死对比关系） |
| 【风格基调】 | 写实电影 / 二次元动画 / 赛博科幻 / 水墨国风 / 停格黏土……**只选一种并写明** |
| 【总时长 / 镜头数】 | 常见组合：30s/25镜、10s/5镜、5s/1镜（单镜可跳过分镜层） |
| 【节奏基调】 | 高速密集打斗 / 舒缓叙事 / 悬念惊悚 / 炫技展示 |
| 【可选：台词】 | 若有台词，写明语言、语气、大致字数 |

> ⚠️ **核心资产写死原则**：角色、武器/载具、光效颜色形态一旦在设定卡定下，分镜中每次出现必须用**同一表述**，这是防崩坏的关键。

---

## 第一层：统一 Style（全局风格层 · 全镜头共用）

> 句式骨架：**画质 → 渲染/材质 → 光影 → 色调 → 动态元素 → 特效体系 → 构图氛围 → 一致性 → 节奏**
> 每个槽位都按本次风格填写，与本次题材无关的槽位可删。

```
【画质槽：分辨率+写实度，如 8K 超写实 / 2D 动画赛璐璐 / 像素风】
【渲染材质槽：本次风格的材质关键词，写实片用 PBR 物理材质，动画片用描边质感等】
【光影槽：布光方式 + 亮暗控制要求，如 电影布光、亮部不过曝暗部不死黑】
【色调槽：整体色调与质感，如 暗调胶片颗粒 / 高饱和霓虹 / 水墨淡彩】
【动态元素槽：本片招牌动态，如 速度线 / 花瓣飘落 / 雨幕 / 数据流，铺满画面】
【特效体系槽：本片特效清单，物理真实 + 列举 3-6 种具体特效】
【构图槽：取景基调 + 纵深/空间要求】
【环境动态槽：气流、烟尘、雨雾等环境持续流动的要求】
【一致性槽：主要主体（角色、对手、武器）结构 100% 稳定无崩坏，写明实体感/重量感】
【节奏槽：整体剪辑与动作节奏要求，如 镜头衔接丝滑无拖沓 / 舒缓长镜头】
```

> ✅ 填写原则：风格槽位之间**不得互相矛盾**（如"超写实 PBR"配"赛璐璐描边"就会打架）；一次只锁定一种风格。

## 第二层：分镜脚本（核心骨架）

> 每镜固定格式：`镜头 N (起始-结束 s)` + `运镜：` + `画面：`
> 时间码必须连续无缝。镜头数按总时长换算：每镜 1~1.5s 偏快节奏，每镜 3~5s 偏叙事。

```
### 全套 【N】 镜头 【总时长】 秒精准时长 + 运镜 + 画面提示词

镜头 1 (0-【x.x】s)
运镜：【开场定场类，如：广角前推 / 大远景横摇 / 俯拍下降】
画面：【环境全景交代 + 铺满本次的氛围元素与质感】

镜头 2 (【x.x-x.x】s)
运镜：【主体登场类，如：平移跟拍 / 缓慢上摇 / 剪影现身】
画面：【主角登场 + 神态/造型特写 +（可选）台词】

镜头 3 (【x.x-x.x】s)
运镜：【动作启动类，如：极速推拉 / 手持晃动 / 定点变焦】
画面：【主角由静转动，写出启动方式 + 本片动态元素的首次展现】

镜头 4 (【x.x-x.x】s)
运镜：【追踪类，如：跟尾追踪 / 贴地跟拍 / 甩焦切换】
画面：【第一次高速动作/移动，动态模糊、残影等按本片风格呈现】

镜头 5 (【x.x-x.x】s)
运镜：【对抗互动类，如：环绕锁焦 / 正反打 / 主观视角】
画面：【对手首次攻击 + 主角应对，攻击物与主体交互的粒子/物理反馈】

镜头 6 (【x.x-x.x】s)
运镜：【强调类，如：升格慢放 + 震镜回弹 / 急推急停】
画面：【首次交锋/关键事件！慢放呈现 + 碰撞反馈 + 核心道具的细节流光】

……（中段循环推进剧情：冲突升级 → 陷入危机 → 转折，按题材自由编排）……

镜头 N-1 (【x.x-x.x】s)
运镜：【高潮类，如：多目标同步追踪 / 螺旋环绕 / 多机位快切】
画面：【终极招式/高潮事件，多光效或元素交叉碰撞，主体保持设定形态】

镜头 N (【x.x-总时长】s)
运镜：【收尾类，如：全屏震动定格 / 缓慢拉远 / 黑场渐隐 / 凝固特写】
画面：【最终爆发或结局 → 战后/事后余韵定格：主角姿态 + 环境粒子持续扩散 + 氛围感收束】
```

**叙事节奏公式（按题材替换内容，结构通用）：**

```
动作/战斗片：定场 → 登场 → 启动 → 首次交锋(慢放) → 攻防循环
             → 危机 → 反转/变身(慢放) → 终极对撞 → 定格收尾

叙事/氛围片：定场 → 主体出现 → 细节累积 → 情绪递进(慢推)
             → 关键瞬间(慢放) → 余韵收尾(拉远/渐隐)

产品/展示片：悬念开场 → 主体亮相(环绕) → 功能特写(快切) → 效果演示
             → 全景定格 + 标语位
```

**每个"画面"的通用写法口诀（四段式）：**
1. **谁在动**——点名主体（用设定卡同一称谓）+ 动作
2. **怎么动**——速度/方式副词（瞬间/缓缓/螺旋上升……）
3. **交互与命中**——与谁/什么物体发生交互，命中哪个位置
4. **反馈与细节**——本片特效体系内的粒子/光效反馈 + 一笔材质或神态细节

## 第三层：统一负面提示词（全镜头通用）

> 句式骨架：**画风排除 → 质感排除 → 结构崩坏排除 → 专属一致性禁止项 → 节奏排除 → 专项杂项**
> ⚠️ 核心技巧：设定卡里写死的每一个资产，都要在负面词里写上它的"变坏形态"。负面词要与本次风格**配套**，不要抄别人的（如二次元片别去负面"卡通"）。

```
【画风类——排除与本片风格冲突的画风】如写实片排除：卡通，二次元，手绘，漫画；
  动画片反向排除：真人实拍质感，写实皮肤纹理……
【质感类】质感廉价，色彩失控，过曝，过度柔光，画面死黑，模糊静止，
【结构类】肢体畸形，穿模，结构崩坏，比例失调，多余肢体，
【一致性禁止项——逐个资产写"变坏形态"】
  【武器/载具名】变形 / 短小 / 特效廉价，
  【角色】服饰错误 / 标志性配件缺失（如无冠、无披风、纹样消失）/ 面容崩坏，
  【对手】异化变形 / 添加设定外部位（多肢体、机械化等），
  【分身/召唤物】半透明虚化（若设定要求实体），
【节奏类】主体动作拖沓，站桩蓄力（快节奏片），环境无动态，镜头僵硬骤停，镜头乱抖，
【杂项】字幕箭头，水印，独立漂浮文字，以及本次题材特有的禁止项。
```

## 附：快速套用 checklist

- [ ] 设定卡齐全？风格基调只选了一种且全文一致？
- [ ] 核心资产（角色/武器/对手/光效颜色）表述写死、分镜中复用同一说法？
- [ ] 时间码连续无缝隙？
- [ ] 运镜类型不重复？（定场→跟拍→环绕→升格→俯拍→定格交替使用）
- [ ] "画面"遵循四段式：动作→交互→反馈→细节？
- [ ] 关键节点有强调处理（慢放/定格/急推）？
- [ ] 负面词与本次风格配套，且覆盖所有核心资产的"变坏形态"？
- [ ] 对手/多主体每次出现都强调"保持设定形态、无异常变化"？

## 使用方法

**方式 A：支持整体脚本的工具（即梦故事模式 / Sora / Veo 长视频）**
1. 填好设定卡后，将「统一 Style + 全部分镜 + 负面词」一次性粘贴生成
2. 逐镜检查，只重生成崩坏的单镜，其他镜不动

**方式 B：逐镜生成的工具（可灵 / Runway / 即梦单镜）**
1. 每镜提示词 = **统一 Style + 该镜运镜/画面 + 统一负面词**
2. 用上一镜末帧做下一镜的图生视频参考图，保证角色与场景连贯
3. 按时间码用剪辑工具（剪映/CapCut）拼接

**方式 C：单镜工具（5-10 秒短视频）**
- 跳过分镜层，直接把设定卡内容压缩成一段：风格 + 主体 + 动作 + 运镜 + 光效 + 负面词

## 复用方法

每次只动三处，**结构骨架永远不改**：

1. **设定卡**——换风格基调、角色、场景、光效体系（改这一处会自动带动全文）
2. **分镜画面内容**——套用对应题材的节奏公式重写动作
3. **负面词**——画风类与一致性禁止项要跟着新设定重写

可原样保留的部分：三层层级结构、每镜三件套格式、四段式画面口诀、运镜类型库、checklist 流程。

**切换风格示例（仅示意填法，不代表模板默认值）：**
- 赛博科幻：画质槽→赛博朋克霓虹夜景；特效体系→全息投影、等离子光刃、数据流崩解；负面词排除→低饱和乡土风、蒸汽朋克元素
- 国风水墨：画质槽→水墨晕染动画质感；动态元素→墨迹飞溅、宣纸留白；负面词排除→写实皮肤、3D 渲染痕迹
- 美食特写：画质槽→微距超写实；光影槽→柔光棚拍布光；运镜库→环绕食物/俯拍慢推；负面词排除→廉价塑料餐具感、生冷色泽
