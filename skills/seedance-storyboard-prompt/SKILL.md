# Seedance 分镜提示词流水线

> 路径约定：本文件内所有路径均为**技能目录内的相对路径**（`references/` `scripts/`）。安装到 `~/.workbuddy/skills/<name>/` 或 `~/.codex/skills/<name>/` 后结构不变，可直接用。

## 开场必读

1. 先读真源规范：`references/seedance-prompt-spec.md`（本文件只是流程索引，规范是唯一真源）。
2. **表情优先筛选**：先读 `references/expression-library.md`，从 31 条标准词条里挑最贴近的一条引用，写作「表情【词条名】」；**严禁自造近义词**；库内无贴合词条才标「表情【自定义：…】（待确认）」并与用户沟通。
3. **电影技巧优先查库**：`references/cinematic-techniques.md`（或同名 .json）收录 melies.co 全站 **424 条技巧**（13 类：镜头运动 86 / 构图景别 25 / 角度 19 / 灯光 41 / 构图 32 / 镜头光学 17 / 色彩胶片 19 / 时间运动 21 / 机内特效 57 / 剪辑转场 23 / 氛围天气 13 / 类型风格 27 / 病毒风格 44），每条含别名、定义、叙事功能、怎么拍、何时用/不用、近似对比、片中实例、**Prompt 模板**、示例 Prompt、常见错误。**选镜头语言/灯光/构图/风格时先查本库挑词条**，选中的把 Prompt 模板翻译/本地化进 Shot 的「镜头」「光影」字段；库内无贴合再自造，并注明。词条正文为英文原文，直接引用 Prompt 时可整段英文嵌入中文提示词。
   - **检索方式（二选一）**：① 跑脚本（推荐，输出精简）`python scripts/search.py 压迫感 --n 6`，支持中文意图词/英文关键词/`--cat` 限定分类/`--name "xxx"` 取全文/`--full` 全字段/`--intent` 列意图词；② 直接 Grep `references/cinematic-techniques.md`。**不要整篇 Read 这个 1.3MB 文件**。
   - **感觉词 → 专业词条**：先查 `references/intent-to-technique.md`（意图映射表，含情绪/场面/时间/光线/风格五类 + 组合配方），把"压迫感""燃""反转要狠"翻译成具体词条，再用上面的检索脚本取全文。

## 怎么调用

三种方式任选，效果一样：

1. **斜杠命令**：`/seedance-storyboard-prompt`
2. **说人话触发**：「写 Seedance 提示词」「补全分镜」「买量视频分镜」「帮我优化这个想法」「这里镜头怎么拍」「这里用什么光」
3. **连想法一起丢**（推荐，最省事）：

```
/seedance-storyboard-prompt

想法/剧情：（一句话或几句情节，越粗越好，细节我来补）
想要的感觉：（如"要压迫感""这里要燃""反转要狠" —— 不写我就按剧情推断并标注）
风格：（不写套默认 3D Q 版次世代国风）
时长/镜数：（不写默认 5s 一镜）
画幅：（不写套 9:16 竖版）
参考图：（有就给路径，没有就留空，我写「待补」占位）
```

## 阶段零 · 想法优化（用户给的是粗略想法/一句话/毛坯脚本时必走）

当用户给的很粗（一句话、几句情节、无镜头语言、无光线设计），**不要直接进阶段一**，先做优化提案，等用户选定后再展开成脚本。

**5 步：**

1. **拆意图**：从原文里抽出情绪/场面/节奏/风格四类意图。用户没写的，按剧情类型**合理推断**并标注「（推断）」，不自作主张改剧情。
2. **查库选型**：每个意图 → `references/intent-to-technique.md` 找候选 → `scripts/search.py` 取定义与 Prompt 模板。每类给 **2–3 个候选**，不要只给一个。
3. **出提案表**（格式固定）：

   | 意图（原文/推断） | 候选技巧 | 推荐 | 理由 | 对原想法的具体改写 |
   |---|---|---|---|---|

   推荐项要写清**为什么选它、放弃了什么**（例："Dolly Zoom 比 Crash Zoom 更贴'认知崩塌'，后者偏喜剧 sting"）。
4. **给改写对照**：把用户原文和"套用技巧后"的写法并列，让他一眼看出变化。**只在镜头语言/光线/节奏层面改写，不改剧情和台词**。
5. **等确认**：用户拍板（或说"你定"）后才进阶段一展开完整脚本。

**硬约束**：一镜只用**一种主导镜头运动**；情绪靠「运动 + 角度 + 光 + 景别」组合，不靠堆词；引用模板前扫一眼该词条的「何时不用/常见错误」，少数模板段落是反例。

## 两阶段流程（不跳步）

**阶段一 · 完整分镜脚本（先交付，等用户确认）**
1. 全局风格块（无指定则套默认：3D Q 版次世代国风 + PBR + 电影级游戏 CG）。
2. 资产清点建锚定表；**参考图没生成的位置写「（参考图：待补）」占位**，图到位后只回填编号。
3. 切分镜头：**一 Shot = 一镜 = 1 个主事件**；装不下就拆，编号顺延、时间轴接续。禁止镜内切镜。
4. 每镜：焦段 + 景别 + **景深与焦点（浅景深必须写焦点锁谁）** + 运动 + 机位数值（位置/离地高度/朝向）。
5. 站位（画面空间顺序）+ 光照（时段+光源+方向+光质+氛围，开放式电影灯光描述）+ 动作微表情（**表情库优先筛选，此处写「表情【词条名】」简称**）+ 台词。
6. 输出完整脚本，交用户确认。

**阶段二 · 提示词生成（确认后）**
7. 回填参考图编号，更新锚定表。
8. 按规范 §4 公式拼装，**把所有「表情【词条名】」展开成具体描述**（眼部+嘴角+面部），交付时按规范 §9.3 的「整段可复制」格式输出（见下方硬规则）。
9. 同期声 + 全局约束校验，输出。

## 硬规则（踩过坑的）

- **【表情必须展开，禁止只写词条名】**「表情【极致震惊】」这类**只出现在阶段一脚本里**（给人核对用）。阶段二拼进提示词时**必须展开成具体描述**：保留「眼部状态 + 嘴角状态 + 面部状态」三个维度，可压成一句连贯中文，但**绝不出现【词条名】**——模型不认词条名，只认描述。示例：`表情【极致震惊】` → `双眼骤然睁大瞪圆、瞳孔收缩、眉头高挑上扬；嘴唇微张、嘴角向两侧平拉发僵、下颌微垂；额肌收紧、面部肌肉僵住、血色略褪`。
- **【最高优先级】交付必须是「整段可复制」的 Shot 块**，格式固定为 `Shot NN / 风格： / 镜头： / 拍摄内容： / 同期声： / 时长：`。风格与负面约束**内联进「风格：」字段**；参考图清单、备注、风险提示**一律挪到文件末尾独立小节**，绝不插在 Shot 块里打断复制。用户是整段选中直接粘进生成器的，**不能要求他做任何拼接**。
- 机位必须数值化（"摄影机位于 X，离地 N 米"），禁止模糊位置。
- 5s 一档；超 1 主事件拆 Shot，不硬塞。
- 系统弹窗文字 = 画面内 UI，写"清晰显示白色文字"+ 文案原文照抄。
- 配角情绪按递进链推进：嘲讽冷怒 → 轻柔错愕 → 极致震惊 → 慌张惊恐 → 麻木绝望（配角的反应线 = 主角的爽感刻度尺）。
- 循环/卡点镜头走首尾帧同图锁定；叙事推进镜头不锁。
- 默认参数：seedance2.0fast_vip / 5s / 每镜 1–4 张参考图。
- 用户发长图（如表情参数表）会被压成窄条不可读 → 要文件路径，本地 PIL 竖向切片 2000px/片后逐段读取。

画幅（16:9 vs 9:16）· 音频（音画同生 vs 后期 TTS）· 弹窗生成方式 · 参考图命名。

## 示例项目参数（参考，可替换为你自己的项目）

下面是某个三国买量片（《逆天吹牛系统》）的定稿参数，仅作参考：

- 画幅 **9:16 竖版**；音频**音画同生**；系统弹窗**画面内直接生成**，文字由**机械音色画外音**朗读；模型 `seedance2.0fast_vip`（大场面镜换 `seedance2.0`）。
- 竖版构图铁律：多人同镜改纵深/前后排布；大全景纵向延伸；低角度大场面运动向上出画；落版主体占上 2/3、底部留 1/3 净空给 CTA；弹窗放人物下方/侧下方不遮脸。
