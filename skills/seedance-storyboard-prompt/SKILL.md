# Seedance 分镜提示词流水线

## 开场必读

0. **先读规则卡（最重要，`规则卡_v4.txt`，约 1.5K 字）**：**官方写法六条铁律 + 一条一段自然语言模板 + 整数秒时间线 + @图片N 主体锚定 + 「整体…」收尾句 + 4-15s 自选 + 已废止旧写法清单**都在这一张里，**每次动笔前先读它、交付前按它复述**。它解决的是「规范太长、硬规则执行率衰减」的问题——细节冲突时一律以规则卡为准。**v4 是照官方《即梦 Seedance 2.0 使用手册》全文重写的**（提炼文档 `outputs/Seedance2.0_官方写法提炼_v1.md`），之前的 v2/v3/v3.1 那套（三字段 / 0.5s 粒度 / 做完即停 / 静止到末帧 / 按 5 秒档生成再裁）**已全部废止**。
1. 规范全文是查阅层：`references/seedance-prompt-spec.md`（本 skill 只是流程索引 + 资料入口，规范是唯一真源），需要时才按章节翻，**不要整篇塞进上下文**。
2. **表情优先筛选**：先读 `outputs/人物表情描述库_v1.md`，从 31 条标准词条里挑最贴近的一条引用，**并当场展开为「眼部 + 嘴角 + 面部」三维度描述（全流程双写，脚本与提示词同样处理，禁止只写【词条名】裸奔，详见下方硬规则）**；**严禁自造近义词**；库内无贴合词条才标「表情【自定义：…】（待确认）」并与用户沟通。
3. **电影技巧优先查库**：`references/cinematic-techniques.md`（或同名 .json）收录 melies.co 全站 **424 条技巧**（13 类：镜头运动 86 / 构图景别 25 / 角度 19 / 灯光 41 / 构图 32 / 镜头光学 17 / 色彩胶片 19 / 时间运动 21 / 机内特效 57 / 剪辑转场 23 / 氛围天气 13 / 类型风格 27 / 病毒风格 44），每条含别名、定义、叙事功能、怎么拍、何时用/不用、近似对比、片中实例、**Prompt 模板**、示例 Prompt、常见错误。**选镜头语言/灯光/构图/风格时先查本库挑词条**，选中的把 Prompt 模板翻译/本地化进 Shot 的「镜头」「光影」字段；库内无贴合再自造，并注明。词条正文为英文原文，直接引用 Prompt 时可整段英文嵌入中文提示词。
   - **检索方式（二选一）**：① 跑脚本（推荐，输出精简）`python scripts/search.py 压迫感 --n 6`，支持中文意图词/英文关键词/`--cat` 限定分类/`--name "xxx"` 取全文/`--full` 全字段/`--intent` 列意图词；② 直接 Grep `cinematic-techniques.md`。**不要整篇 Read 这个 1.3MB 文件**。**默认输出已含「避坑」行**（自动抽出该词条的 Do not / 常见错误），引用模板前必看——少数模板段落是反例（如 Low Angle 模板写 "no dramatic upward angle"）。
   - **感觉词 → 专业词条**：先查 `references/intent-to-technique.md`（意图映射表，含情绪/场面/时间/光线/风格五类 + 组合配方），把"压迫感""燃""反转要狠"翻译成具体词条，再用上面的检索脚本取全文。
4. **特效/转场写法查库（变身·觉醒·尺度潜降等跨镜头序列）**：`references/effect-library.md` 收录**跨镜头的高级特效序列/转场写法**（与 424 条单镜头技巧库互补，不冲突）：① 变身/觉醒/形态切换 四幕结构 + 可复用英文 Prompt 词汇表（提炼自两段参考提示词，原文逐字保留）；② 尺度潜降微世界转场 五段骨架 + 命门 + AI 落地方案。写剧情含 **变身/觉醒/形态切换/力量爆发/神格化/魔化/机甲合体/尺度潜降微世界转场** 时，先查本库复用写法（见下方硬规则）。**检索**：`python references\_tools\effect_search.py 变身 --full` 或 `尺度潜降 --full`；也可直接 Grep 本文件（文件小，可整篇 Read）。
5. **打斗/动作戏优先查手册**：`references/combat-handbook.md`（真源副本同步自 `references/combat-handbook.md`，约 40KB，体积小**可整篇 Read**）收录一套打斗提示词写法规范：七层结构 / 分镜固定字段序 / 打击感五件套 / 环境交互四段式 / 力量四阶梯与代价感 / 七类关键词库 / 三套可套用模板（近身肉搏·兵器对决·超能力对轰）/ §5.1「需求词→模块」映射表 / §5.2 症状→修正表 / §5.3 取舍优先级 / §5.4 禁用清单。**触发条件**：剧情含 **打斗 / 战斗 / 交手 / 对决 / 搏杀 / 追杀 / 火拼 / 群战 / 怪物搏杀 / BOSS 战**，或用户提 **炫酷打斗 / 强化打击感 / 丰富特效 / 动作不流畅 / 打击感 / 动作戏 / 镜头要连贯** 等需求。**怎么用**：① 先读 §1.3 固定字段序与 §0.5 检索锚点表；② 逐镜按「开局站位状态 → 镜头 → 动作 → 台词 → 情绪 → 特效 → 声音（前景/背景）」落字段；③ 每镜自检 §2.3 打击感五件套是否凑齐；④ 用户提需求词时按 §5.1 取模块改字段，**不重写全篇**。本手册与 424 条技巧库、effect-library 三者互补：技巧库供单镜词条、effect-library 供变身/尺度转场序列、本手册供打斗整体规范与模板。

## 阶段零 · 想法优化（用户给的是粗略想法/一句话/毛坯脚本时必走）

当用户给的很粗（一句话、几句情节、无镜头语言、无光线设计），**不要直接进阶段一**，先做优化提案，等用户选定后再展开成脚本。

**5 步：**

1. **拆意图**：从原文里抽出情绪/场面/节奏/风格四类意图。用户没写的，按剧情类型**合理推断**并标注「（推断）」，不自作主张改剧情。
2. **查库选型**：每个意图 → `intent-to-technique.md` 找候选 → `search.py` 取定义与 Prompt 模板。每类给 **2–3 个候选**，不要只给一个。
3. **出提案表**（格式固定）：

   | 意图（原文/推断） | 候选技巧 | 推荐 | 理由 | 对原想法的具体改写 |
   |---|---|---|---|---|

   推荐项要写清**为什么选它、放弃了什么**（例："Dolly Zoom 比 Crash Zoom 更贴'认知崩塌'，后者偏喜剧 sting"）。
4. **给改写对照**：把用户原文和"套用技巧后"的写法并列，让他一眼看出变化。**只在镜头语言/光线/节奏层面改写，不改剧情和台词**。
5. **等确认**：用户拍板（或说"你定"）后才进阶段一展开完整脚本。

**硬约束**：一镜只用**一种主导镜头运动**；情绪靠「运动 + 角度 + 光 + 景别」组合，不靠堆词；引用模板前扫一眼该词条的「何时不用/常见错误」，少数模板段落是反例。

## 口播驱动分镜（用户给了配音/口播音频文件时，必走）

**不要凭感觉估每句口播的时长，先量化断句。** 拿到音频路径后第一步跑静音检测：

```bash
ffprobe -v error -show_entries format=duration -of default=noprint_wrappers=1 "路径.mp3"
ffmpeg -hide_banner -nostats -i "路径.mp3" -af silencedetect=noise=-32dB:d=0.18 -f null - 2>&1 | grep -E "silence_(start|end)"
# 停顿太短没检出来时，放细一档：noise=-38dB:d=0.10
```

拿到每个语音段的起止秒数后：

1. **先建「音频节拍对照表」**（语音段 / 口播原文 / 起–止 / 时长），写进脚本文件——这是分镜时间轴的唯一依据，也是后面剪辑对齐用的表。
2. **字幕数校验**：`中文字数 ÷ 语音时长` 应在 **4.5–7 字/秒**。若某段算出来远超 7 字/秒，说明你**把两句话并成了一段**（漏检了中间的短停顿），回去放细阈值重测；反之若低于 3 字/秒，说明停顿被当成了语音段。
3. **切镜规则**：镜头边界优先落在**静音区间**里；用户要求「尽可能多切」时，可以在**同一语音段内部**按动作另加切点（一个语音段拆 2–3 镜），但单镜**不短于 0.5 秒**。
4. **插入镜（0.5–0.8s）**在备注里注明「可从相邻镜的同批素材里裁，不单独跑生成」，避免浪费生成额度。
5. **口播是旁白还是台词**要问清：若是画外音旁白（第一人称"当年我…"之类），**画面内人物一律不开口、不做口型**，否则口型会和旁白打架；同期声字段只写环境音与动作音效，人声由后期贴。
6. 口播本身是已录好的音频时，**成片通常无 BGM**（口播独占声场），同期声只留音效。

## 两阶段流程（不跳步）

**阶段一 · 完整分镜脚本（先交付，等用户确认）**
1. 定风格（无指定则先问用户「真人实拍写实还是 3D/动画」，别默认套 3D 卡通；风格写在每条开头那句与结尾的「整体…」句里，v4 没有独立的全局风格块）。
2. 资产清点建锚定表 → **【资产问询，不许跳过】**清点完先问用户两件事：①哪些资产已有图（请传文件路径）；②无图资产要不要我逐个写**生图提示词**（可直接生成资产正稿）。答复后按规范 §2.2.1 二分法定形态：有图 → 「（图片 N）作为……视觉锚定」；无图+要生图提示词 → 「（无图·文字生图）」行直接写完整生图提示词（角色=五要素全展开；场景=时段+内外景+结构材质+光源光质；元素=材质+结构+细节）；无图+不要 → 纯描述锚。**禁止无图却写「（图片 N：待补）」空引用**。后期用户补图，把该行升级为引图锚，描述保留。
3. **定生成条数与时长分配**：按剧情把总时长切成 1-N 条，**每条 4-15 秒自选**（想要几秒就选几秒，**不写「按 5 秒档生成、只取前 X 秒」**）。**一条就能出 15 秒、内含 4-5 个分镜**；快节奏用「快速闪切 / 快速切换 / 依次定格」写在一条里，**不是靠生成更多条**。把「条号 / 生成时长 / 累计」写进说明区，Σ = 用户要的总时长 ±0.5s。用户给了口播/配音音频时，先跑静音检测再定条长，别凭感觉估。
   3.5. **【一条写满 15 秒的实操 · 2026-09-29】** 时间线用**变长段**（如 0-3秒 / 3-5秒 / 5-8秒），**不要写 15 个 1 秒段**——官方模板本身就是变长段，写 1 秒段既啰嗦又稀释每段的信息密度；check_beats.py 只校验「段长 ≥1 秒且为整数秒 / 从 0 起 / 首尾相接 / 末段止点 = 生成时长」，变长段天然合规。
   3.6. **【时间线格式】** 写成 `0-3秒画面：<景别运镜>，<谁做什么>（情绪：xx）。3-5秒画面：切镜，<谁做什么>，说："台词"。`——**整数秒、从 0 起、段与段首尾相接、末段止点 = 该条生成时长**。景别运镜 / 动作 / 情绪 / 台词**全部混写在句子里**，不单列字段、不打标签。
   3.7. **【换过环境就得切回来 · 2026-09-29，最容易漏】** 时间线里一旦快切离开主场景，回到主场景那段必须写 ①「切回XX」② 主体当前姿势（仍躺 / 仍被压 / 仍蹲）。漏了前者，后半场会接在最后一个快切场景里；漏了后者，躺着的人会自己站起来。
   3.8. **【不写「左手/右手」，一律写画面方位 · 2026-09-29，镜像 bug】** 模型对「身体左右 ↔ 画面左右」的映射不稳定：写「伸出右手」，它可能把整个身体镜像翻转，把手生成到画面另一侧、弯曲方向还按原姿势 → 出来就是**反关节的左手**（观感上「右手长在左手的位置」）。三级修法：① 全文删掉「左/右」字样，身体方位改画面方位——「靠近画面右侧的那条手臂」；② 给画面坐标 + 朝向——「自画面右下角斜伸向画面左上方，掌心朝下、手背朝上、肘部在外侧微屈、手腕不外翻」；**关键是「掌心朝下/手背朝上」**，就算仍镜像，朝向大概率能保住，反关节就不会出现；③ 唯一性约束——「另一条手臂始终被压住、不得抬起，全片只出现这一只自由手」。还翻就按顺序退：换更好画的姿势（侧躺 > 仰躺）→ 让两只手都出来（消除歧义）→ 手部特写改正俯拍（画面里没有左右、只有前后）。**别反复强调「是右手、不是左手」**——越强调左右词，模型越在意左右，越容易翻。
   3.9. **【空间摆位用画面坐标钉死，回来时逐字复述 · 2026-09-29】** 只写「A 压着 B」这种关系描述不够——模型每段按自己的理解重摆，快切离开主场景几秒再回来，人的位置、朝向、机位全会变。开场第一句就写成画面坐标（`主体1仰面躺在画面下半部、头朝画面左侧、双脚朝画面右下角；主体2骑压在他腰腹上方、背对镜头、头在画面上方偏右`），中途离开主场景再回来时**逐字复述同一段坐标** + 一句「机位、摆位回到开场那一镜」；配角倒地位置、道具位置也一并定死，别让两处打架。
   3.10. **【同构段合并】** 连续 3 段以上机位同、动作同、只换环境元素（地面材质 / 背景物件）→ 合并成 1-2 段，用「元素在一镜内递变 + 速度力度递变」体现推进。**排除项只写进每条结尾的「整体…」句，严禁逐段复述。**

4. **【查技巧库（可选加料，不再强制）】** 需要特定镜头语言时跑 `python <skill>/scripts/search.py <意图词> --n 6`，从 424 条里选运动 / 景别 / 焦段 / 角度 / 光学 / 特效词，中英并列嵌进句子里（如「极慢推近 slow push-in」）。**v4 不再要求每镜标「技巧依据」**——只在需要精细镜头设计时才查。
5. **【角色锚定】** 每条开头用 `@图片N` 锚定一次——`将@图片1的黑衣胖子作为主体1，@图片2的壮汉作为主体2`——后文统一叫「主体1 / 主体2 / 主体3」，前后不混用角色名。景别运镜用自然语言写进句子（`贴地低角度侧拍`、`镜头跟随`、`缓慢推近`），**不强制写「离地 X 米」数值**（只有要精确对齐参考图时才补）。
6. **【光影与色调】** 不单列「光线：」字段。局部光影写进对应时间段，**整体色调与光质打包进结尾的「整体…」句**：`整体写实电影质感，自然日光暖调、硬光与墙影对比强烈`。
7. **【台词与画面内的字】** 直接写进句子：台词 `绝望大喊："杰哥！不要啊！"`，画面内字幕 `字幕弹出"再忙也要记得吃点零食~"`。**剧本台词逐句都要在，一句不能漏、一个字不能改**——压缩时最先被误砍的就是台词。表情用 `（情绪：恐慌、窒息）` 紧跟动作即可；表情库三维度展开（眼部 / 嘴角 / 面部）已降级为「需要精细控制时的可选加料」，不再强制。
8. **自检后输出（两区制 + 字数自检 + 时长核对）**：可复制区（各条提示词正文，**每条以【第 N 条 · 生成时长选 X 秒】开头、正文是一段自然语言、≤2000 字**，条间独立一行 `====`，无任何元信息）→ 分隔线 → 说明区（时长核对/参考图挂载/**台词核对表**/字数表/技巧依据/执行参数/备注/自检清单）。自检项：全篇无字段标签 → 每条声明生成时长且在 4-15s → 时间线整数秒 + 从 0 起 + 首尾相接 + 末段止点 = 该条生成时长 → 各条时长之和 = 目标 ±0.5s → 每条有「整体…」收尾句（含色调/光影/节奏/声音/排除项）→ 有 @图片N 锚定且后文统一叫主体N → **字数 ≤2000（写长要每句为画面付费）** → **中途换过环境的，切回主场景写了「切回XX」+ 主体当前姿势** → **全文无「左手/右手」，手部用画面方位 + 掌心朝向 + 唯一性约束写** → **开场把人物摆位写成画面坐标、离开主场景后回来时逐字复述同一坐标** → **剧本台词逐句都在、原文未改（压缩时最先被误砍的就是台词与环境）** → 无已废止旧写法 → **（打斗戏加检）打击反馈五件套凑齐、场景层已预声明可破坏性、上一镜破坏痕迹在本镜被继承** → 交用户确认。

**阶段二 · 提示词生成（确认后）**
9. 用户补发资产图后，把对应「（无图·文字生图）」锚定行升级为「（图片 N）」引图锚（描述保留），更新锚定表。
10. 按官方句式模板拼装每条：`将@图片1的<角色>作为主体1，@图片2的<角色>作为主体2。<一句话讲清这条演什么>。0-2秒画面：<景别运镜>，<谁做什么>（情绪：xx）。整体画面<色调>、<光影>，节奏<xx>，搭配<声音>，全程突出<卖点>，无<排除项>。`**v4 没有「全局锁」这个概念**——风格与资产锚定写进每条开头那句，排除项写进结尾的「整体…」句，不要另起一段「【全局锁】」。
11. 逐条核对：时间线整数秒且首尾相接、末段止点 = 生成时长、有「整体…」收尾句、有 @图片N 锚定、剧本台词齐全、中途换过环境的已「切回」、**全文无左右手字样（改用画面方位）、空间摆位已用画面坐标钉死且回归处复述**、无已废止旧写法。
12. **【交付前自检，不可跳过】** 跑 `python <skill>/scripts/check_beats.py <文件.txt> --total <目标秒数>`（**v4 官方式专用，已含字数检查**，count_chars.py 只作旧稿遗留工具）。一次过检：每条声明生成时长且在 4-15s / 时间线整数秒 + 1 秒粒度 + 从 0 起 + 首尾相接 / **末段止点 = 该条生成时长** / 各条时长之和 = 目标 / 每条有「整体…」收尾句 / 有 @图片N 素材锚定 / **字数 ≤2000（官方上限，2026-09-29 更新；旧的 500 字限制作废；写长必须每句都为画面付费，>1200 字时脚本会提醒复查）** / **无已废止旧写法**（时序 / 做完即停 / 完全静止到末帧 / 三字段 / 按 5 秒档生成 / 只取前 X 秒）。退出码非 0 就是有违规，改完重跑。

## 硬规则（踩过坑的）

- **【表情：v4 已降级为可选加料】** 默认只写 `（情绪：恐慌、窒息）` 紧跟动作。下面这条三维度双写**仅在用户要求精细表情控制时才用**，不再是硬性要求：`表情【极致震惊】——双眼骤然睁大瞪圆、瞳孔收缩、眉头高挑上扬；嘴唇微张、嘴角向两侧平拉发僵、下颌微垂；额肌收紧、面部肌肉僵住、血色略褪`。展开保留「眼部 + 嘴角 + 面部」三个维度，可压成一句连贯中文但三维度都要在。**任何地方出现孤零零的【词条名】都算违规**——模型不认词条名，用户也不该再手动展开一次（2026-09-20 二次纠正：旧规则允许脚本只写简称，导致脚本直接被拿去用时模型读不懂）。
- **【全局锁 · v4 已废止，见到旧的就删】** v4 是「一条 = 一段自然语言」，**没有独立的【全局锁】段落**。风格串、资产锚定写进每条开头那句（`将@图片1的黑衣胖子作为主体1…`），排除项写进结尾的「整体…」句。旧版「全局锁只写一次、放在整篇最开头」「锚定句只住全局锁、绝不写进正文」这类规则随三字段一起作废；**保留的只有一条通用原则**：同一句约束不要在同一条里重复写两遍。
- **【禁表格 · 2026-09-20 用户投诉】提示词交付物里一律不要写 Markdown 表格**。表格会让用户在 WorkBuddy 预览面板里**选不中、复制不了内容**，用户为此明确投诉过。**Shot 块之间用 `====` 分隔线隔开，块内部只写「字段：内容」的纯文本行**；参考图挂载、参数、风险提示放文件末尾，同样用纯文本行，不用表格。
- **【交付文件优先 `.txt` 而非 `.md` · 2026-09-20】** `.md` 会被预览层渲染，用户反映复制不了。阶段一给人核对的脚本可以用 `.md`，**阶段二要复制粘贴的提示词一律 `.txt`**。
- **【阶段一同样适用】**：阶段一脚本虽然是给人看的，但只要用户可能复制其中的描述去用，就一样遵守「禁表格 + 整段可复制」。别因为「这是脚本不是提示词」就放松。
- **【角色锚点名只在出场镜出现 · 2026-09-20 渲染事故】** 别用别的角色当方位参照（「与 @A 相对的另一端」「A 的左侧」）——等于把 @A 这个参考图锚点塞进了不该有他的镜头。实战：三人登场镜写了「与 @昆顿 相对的另一端」，模型照单全收，三人画面渲出了第四个人。硬规则：① 不出场的角色名字**一次都不能提**，方位改用纯空间描述（「远离断崖的这一端」「画面深处」）；② 每个 Shot 正文补一句在场清单约束（「画面内只有三人，无第四人、无魔物、无远处崖顶身影」）；③ 排除项（写进每条结尾的「整体…」句）兜底「除正文点名外禁止出现未点名角色」；④ 说明区写明该镜**只挂哪些参考图**，生成端也不要多挂。
- **【一次性特效必须写熄灭动作 · 2026-09-20】** 降临光柱、传送门、爆点这类瞬态特效，若只在场景锚/光线行写成「中心垂下贯穿光柱」，模型会当成**常驻布景**全片保留。硬规则：① 光线描述声明「一次性：只在角色现身瞬间贯下，形体清晰后即收束熄灭，画面常态无光柱」；② 每个用到该特效的 Shot 正文**必须写一个熄灭动作句**；③ 后续镜头正文明写「天幕无光柱」；④ 靠它提供的边缘光改用「落点地面残留余辉」这类说法，别写「尚未散尽的光柱」。
- **【字数与压缩顺序 · v4 · 2026-09-29 修订，取代 2026-09-20 那版】** 官方上限 **2000 字/条**（计量单位 = **单条提示词正文**，不是整篇文件）。**没有硬性下限**——官方案例 80-250 字是「够用就停」的示范，15 秒三幕这种信息量大的写到 900-1000 字很正常（实测「摸蛋反击」单条 15 秒 = 941 字）。**压缩顺序（反过来就是砍字顺序）**：① 砍形容词与次要修饰 → ② 砍环境材质细节 → ③ **台词与环境交代是硬内容，不许砍**（剧本原文一句都不能漏、一个字都不能改）。**实测踩过三次**：为卡字数先后砍掉了「环境回到主场景的交代」「蛋的大特写细节」「剧本台词后半句」——**规律：字数压力下的第一反应是砍描述，而描述里藏着硬内容**。旧版「全局锁 ≤900 / Shot 正文 ≤1100 / 同期声留 3-5 条」的分段预算已随三字段一起作废。
- **【官方式写法 · v4 · 2026-09-28 按官方《即梦 Seedance 2.0 使用手册》全文重写，取代 v2/v3/v3.1 全部时长治理规则】** 用户原话：「你好好学习这个 seedance2.0 的官方教程，以后写提示词就按照他这个形式来写」「不要弄得太复杂」。**三条推翻旧设计的官方事实**：① 官方「生成时长 ≤15s，可自由选择 4-15s」——**不存在只有 5s/10s 死档这回事**，所以「按 5 秒档生成、只取前 X 秒」「X+Y=5」这一整套全部作废；② 官方提示词**是一段自然语言，没有字段标签**，官方案例 80-250 字、最短 29 字，我们之前每镜 700-1100 字是严重超配；③ **一条 prompt 就能出 15 秒、内含 4-5 个分镜**，靠「0-3秒画面：… / 3-6秒画面：…」写时间线，快节奏用「快速闪切 / 快速切换 / 依次定格」写在一条里，**不是靠生成更多条**。**六条铁律**：① 一条 prompt = 一段自然语言，不分字段不打标签；② 长度**官方上限 2000 字**（2026-09-29 官方更新，旧的 500 字限制是我们自己加的、已作废）——官方案例 80-250 字只是「够用就停」的示范，不是天花板；**写长可以，但每句都要为画面付费**：新增文字必须对应画面上真实可见的东西（环境材质 / 光影 / 表情 / 动作细节 / 声音），**不许堆同义形容词、不许把同一件事换三种说法**（那是稀释注意力，不是增强）；③ 时间线「0-1秒画面：…」——**整数秒、1 秒粒度、从 0 起、首尾相接、末段止点 = 该条生成时长**；④ 角色用「@图片N」锚定一次、后文统一叫「主体1/主体2」；⑤ 结尾一句「整体…」打包色调 + 光影 + 节奏 + 声音 + 排除项；⑥ 一次生成 = 4-15 秒自选。**官方句式模板**：`将@图片1的<角色>作为主体1，@图片2的<角色>作为主体2。<一句话讲清这条演什么>。0-2秒画面：<景别运镜>，<谁做什么>（情绪：xx）。2-5秒画面：切镜，<谁做什么>，说："台词"。整体画面<色调>、<光影>，节奏<xx>，搭配<声音>，全程突出<卖点>，无<排除项>。`**已废止（见到即删）**：三字段（镜头/拍摄内容/同期声）、Shot 标题行时间段、0.5s 粒度与亚秒数、「一气呵成做完即停」、「画面完全静止持续到最后一帧」（仅首尾帧循环视频保留）、「按 5 秒档生成/只取前 X 秒」、「X+Y=5」、机位必须写「离地 X 米」、每镜复述全局负面约束、表情库三维度强制双写。**要精确复刻运镜/动作 → 上传参考视频 + 一句「参考@视频1的运镜」「模仿@视频1的动作」**，比写一百字描述有效得多。**换过环境就得切回来（2026-09-29 补，最容易漏）**：时间线里一旦快切离开主场景，回到主场景那段必须写 ①「切回XX」② 主体当前姿势（仍躺/仍被压/仍蹲）；漏了这两句，模型会把后半场接在最后一个快切场景里、还会让躺着的人自己站起来——实例：巷子被打 → 中间 8 秒手在沙地雪地快切 → 砸头镜只写「抡起主体3砸中头部」，结果是人在草丛里站着砸。正确写法：「切回巷弄，主体1仍仰面被压在地上、抡起主体3砸中主体2头部」。**一条写满 15 秒的实操**：时间线用**变长段**（如 0-3秒 / 3-5秒 / 5-8秒），**不要写 15 个 1 秒段**——官方模板本身就是变长段，写 1 秒段既啰嗦又稀释每段的信息密度；check_beats.py 只校验「段长 ≥1 秒且为整数秒 / 从 0 起 / 首尾相接 / 末段止点 = 生成时长」，变长段天然合规。
- **【左右手镜像 bug · 2026-09-29 实测】** 写「伸出右手」却生成**反关节的左手**（观感：右手长在左手的位置）——根因不是模型不认「右」字，是**整个身体被镜像翻转**、而手臂弯曲方向还按原姿势，一挪位置就成反关节。修法：**全文不用「左/右」，改用画面方位 + 掌心朝向 + 唯一性约束**（详见步骤 3.8）。**禁止反复强调「是右手、不是左手」**——越强调左右词越容易翻。退路顺序：换更好画的姿势（侧躺 > 仰躺）→ 让两只手都出来（消除歧义）→ 手部特写改正俯拍（画面里没有左右、只有前后）。
- **【空间摆位一致性 · 2026-09-29 实测】** 只写人物关系（「A 压着 B」）不足以维持跨段空间一致——快切离开主场景几秒再回来，模型会重新摆位，人的位置、朝向、机位全变。必须**开场把摆位写成画面坐标、回归时逐字复述同一坐标**（详见步骤 3.9），配角倒地位置与道具位置也一并定死。
- **【交付两区制 · 最高优先级 · 2026-09-20 用户二次投诉】** 用户拿到手的**每一个交付文件**（阶段一脚本、阶段二提示词）必须物理分成两区，**三根分隔线缺一不可**（分隔线写法以规范 §5.1 为准，16 个等号）：
  - **开头线**：`================ 以下为【可复制区】= 提示词本体，可整段复制 ================`
  - **可复制区（上）**：开头线之后放各条提示词正文（**v4：每条以【第 N 条 · 生成时长选 X 秒】开头，正文是一段自然语言、≤2000 字（官方上限），条与条之间用独立一行 `====`**），**一个多余的字都没有**（连文件头的改动记录、用法说明都不要放在开头线之前，一律挪进说明区）；
  - **结束线**：`================ 以上为【可复制区】结束 ================`　← **必须写，很多人只写开头线就漏了这条**（2026-09-20 自查发现）；
  - **说明区（下）**：`———— 以下为【说明区】，给人核对用的，一律不复制进 Seedance ————` 之后集中放：改动记录、音频节拍表、技巧依据对照（含避坑）、表情词条对照、参考图挂载与文件路径、执行参数（模型/画幅/生成档位建议/用法）、口播对齐表、备注、自检清单。
  - **可复制区禁入清单（出现即违规）**：① 过程备注与修改痕迹，如`（非人角色：无表情词条，参照库内 @关羽机甲 先例）`——非人角色直接写实际视觉描述（如「双眼绿火骤然点亮、亮度渐强」），说明放说明区；② 给人的执行建议，如`建议按 3s 档生成、后期裁切`、`不够再补 5s 档`、`可从同批素材裁切`——包括「单条生成时复制该条正文」这类用法说明也要挪进说明区的执行参数；③ 跨节引用`（见第三节）`；④ 文件名/路径引用；⑤ 技巧依据标注、表情来源说明、参考图清单；⑥ 库名引用`参照表情库`；⑦ **「（站位参考行省略：本项目无站位参考图）」这类说明性占位**——规范 §9.3 写明站位参考行无图就**整行省略**，不要写一行解释为什么省略。
  - **阶段一脚本的可复制区与阶段二提示词正文逐字一致**；禁止出现「五、全局约束 + 执行参数」这种给人看的说明与提示词混排的节——执行参数里只有负面约束（如「画面内人物不开口、不做口型；纯音效，无 BGM」）可进可复制区（写进每条开头句或结尾的整体句），其余全在说明区。
