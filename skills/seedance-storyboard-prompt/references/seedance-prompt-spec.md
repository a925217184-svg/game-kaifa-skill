## 0. 这套规范解决什么问题

把「一段粗略剧情」稳定地变成「Seedance 2.0 能直接跑的分镜提示词」，并且保证：

1. **风格不漂** —— 8 个镜头出自同一个世界观，靠全局块锁死；
2. **角色不崩** —— 每个角色靠 @锚定 + 五要素描述锁死造型；
3. **场景不乱** —— 每个场景靠参考图编号锁死空间与光照；
4. **可批量** —— 你给我粗略脚本，我按第 7 节的流水线补全细节后原样输出。

产物固定为 **三层五块** 结构：

```
[第 0 层] 全局风格块      ← 全片共用，只写一次
[第 1 层] 资产挂载块      ← @角色 / @场景 / @元素 锚定表
[第 2 层] 镜头块 × N      ← Shot 01 … Shot NN，每个镜头的提示词
[附  录] 全局约束 + 参数表
```

## 1. 第 0 层：全局风格块

**写什么**：全片只读一次、不用在每个 Shot 里重复的公共信息。四个必填字段。

| 字段 | 写什么 | 示例 |
|---|---|---|
| 核心风格 | 渲染流派 + 材质 + 题材 + 画面质感，用逗号分隔的名词串 | 3D 卡通 Q 版次世代国风 / 三国系统流爽感 / 手游买量动态漫；cinematic game CG, PBR material texture |
| 影片基调 | 情绪曲线，用 → 连接，5 个词以内 | 戏谑 → 反转 → 递进 → 燃炸 → 爽感 |
| 整体色调 | 一句话色彩策略 | 冷暖强对比的古风战争色调 |
| 光线设计 | 每场戏用什么光：光源类型 + 方向/光位 + 光质 + 氛围目的（开放描述，词库见下） | 见下方电影灯光词库 |

### 光线设计 = 电影灯光描述，开放式

写的是「**这场戏用什么光**」：光源类型 + 方向/光位 + 光质 + 氛围目的。四项自由组合，**不限于任何固定模板**——电影里能设计的光都可以写。下面是按电影布光文献整理的词库，按需取用或自造描述。

**① 布光法（光位与功能）**

| 术语 | 效果 |
|---|---|
| 三点布光（主光/辅光/轮廓光） | 标准人物光，立体干净 |
| 伦勃朗光 | 单侧 45° 高位主光，暗侧脸颊留三角光斑，戏剧感 |
| 蝴蝶光 | 正面高位主光，鼻下蝶形阴影，人物英气 |
| 分割光 / 侧光 | 半亮半暗，表现内心分裂、对峙 |
| 轮廓光 / 边缘光 rim light | 勾勒人物剪影，夜戏分离人物与背景 |
| 逆光 / 剪影 | 背光剪影，登场压迫感、神秘感 |
| 底光 | 自下而上打光，恐怖/诡异/威压 |
| 顶光 | 头顶垂直光，审问感、神情感压抑 |
| 眼神光 catchlight | 瞳孔里的光点，特写提神 |

**② 光质与影调**

| 术语 | 效果 |
|---|---|
| 硬光 | 阴影边缘锐利，冲突、阳刚、战争感 |
| 软光 / 漫射光 | 阴影柔化，唯美、温情 |
| 高调（明亮少影） | 轻快、白天全景 |
| 低调（大面积暗部） | 夜戏、悬疑、压抑 |
| 明暗对比 chiaroscuro | 强反差油画感 |

**③ 实用光源 practicals（画面内真实光源）**

油灯 / 烛火 / 火把 / 篝火 / 灯笼 / 月光 / 晨昏 golden hour / 正午日光 / 阴天平光 / 雾天散射 / 火光 / 爆炸闪光 / 剑气与技能发光（特效光源）

**④ 氛围光效**

体积光 god rays / 丁达尔光束 / 烟雾中光束 / 薄雾柔光 / 冷暖对撞 / 火光映脸跳动 / 闪电频闪 / 水面反光波纹

> **【光线是提示词，不是说明】** 上表只是词库参考。光线设计必须**实例化成文字真正进入提示词两处**：① 全局锁的「光线：」行（按场景类型分档总述，见 §9.3）；② 每个 Shot「拍摄内容」开头的「环境光照」（该镜实际生效的光，从全局锁继承或在该镜「光影」字段补写偏离项）。**只写在风格表里、没进这两处的光线等于没写**（2026-09-20 用户纠正）。

**描述公式**（每个 Shot 的光照都按这个写，一句即可）：

```
[时段/天气] + [实用光源] + [布光法/方向] + [光质] + [氛围目的]
例：夜晚军帐内，暖黄油灯低位主光 + 帐门缝隙冷月逆光，硬光暖冷对撞，营造密谋紧张感
```

**规则**：全局块里只写全片统一的光线策略（如「冷暖强对比的古风战争色调」）；每镜的具体光照在「拍摄内容 ②」里按公式描述，特殊镜头在「光影」字段补充。

## 2. 第 1 层：资产挂载块

### 2.1 命名规范

- 角色：`@曹操`、`@玩家主角`、`@东吴小兵甲 / 乙`
- 场景：`东吴水寨军帐场景`、`赤壁火攻战场场景`
- 元素/道具：`@关羽机甲`、`曹军战船`、`岸防火箭车`
- **@ 符号只用于角色和需要单独锁定的元素**，场景用「XX场景」结尾命名。

### 2.2 四种锚定类型（写参考图时必须标明是哪一种）

| 类型 | 作用 | 写法模板 |
|---|---|---|
| **场景锚定** | 锁定空间、结构、材质、时段、光照 | 「图片 N」作为【场景名】的视觉锚定：<时段><内外景>，<主体结构>，<照明方式> |
| **角色锚定** | 锁定造型、配色、配件、体型、气质 | 「图片 N」作为 @角色 的视觉锚定：3D Q 版国风三国造型，<头饰/发型>，<主色+服装>，<气质/体型> |
| **元素锚定** | 锁定道具/载具/特效单体 | 「图片 N」作为【元素名】的视觉锚定：<材质结构>，<细节特征> |
| **站位参考** | **只参考相对位置与姿态，不直接复刻** | 「图片 N」作为人物在环境中的位置参考：各场景人物站位遵循脚本空间逻辑，仅参考人物相对位置与姿态，不直接复刻使用 |

**组合挂载**：一个场景可以由多张图拼出来，用 `+` 连接。
> 例：赤壁火攻战场场景 = 图片 5（岸防外景）+ 图片 7（战船元素）

#### 2.2.1 锚定来源二分法（2026-09-20 用户定稿）：有图引图，无图写生图提示词

**每条锚定只有两种来源，禁止无图却引用图片编号：**

| 来源 | 锚定行写法 | 说明 |
|---|---|---|
| **有图** | `（图片 N）作为 @角色 的视觉锚定：<五要素描述>` | 图是主锚，描述照写；生成时上传该图 |
| **无图** | `@角色 视觉锚定（无图·文字生图）：<完整生图提示词>` | **不引用任何图片编号**，直接把该资产的完整生图提示词写进锚定行，全片逐镜复用同一份文字，靠文字一致性锁造型 |

**无图锚定的完整度要求**——描述必须达到"拿去生图就能出资产正稿"的水平：
- 角色 = 五要素全展开（造型流派 + 头发/头饰 + 瞳色 + 服装配色 + 标志道具 + 体型气质，参考 §2.3）；
- 场景 = 时段 + 内外景 + 空间结构 + 材质 + 主光源与光质；
- 元素 = 材质 + 结构 + 细节特征。

**流程铁律：先清点，先问，再写**——阶段一清点出脚本全部资产（角色/场景/元素）后，**必须先问用户两件事，不许擅自决定**：
1. 「这些资产里哪些你已经有图了？有图的请传给我（给文件路径）」；
2. 「没有图的资产，要不要我为每个写一段**生图提示词**（可直接拿去生成资产正稿图）？」

用户回答后才定锚定形态：有图 → 引图锚；无图+要生图提示词 → 文字生图锚；无图+不要 → 纯描述锚（此时文字仅描述不承担生图功能）。后期用户补了图，把对应资产的「（无图·文字生图）」行升级为「（图片 N）」引图锚即可，其余不动。

### 2.3 角色锚定五要素（缺一不可）

```
造型流派（3D Q 版国风三国造型）
+ 头部特征（头戴王冠 / 束发 / 纶巾 / 独眼眼罩）
+ 服装配色（黑金战甲 / 束发劲装 / 文士长袍 / 制式甲胄）
+ 标志道具（羽扇 / 佩剑 / 青龙偃月刀 / 长矛）
+ 体型气质（威严英气 / 身形挺拔张扬 / 清俊儒雅 / 身形清瘦 / 瘦小灵动 / 粗犷）
```

### 2.4 参考图编号约定

- 用户以附件形式提供时：用「图片 1…N」按发送顺序编号，规范里建一张 **编号 ↔ 用途 ↔ 场景** 对照表。
- 用户以文件形式提供时：用文件名，并附本地绝对路径。
- 一张图可以被多个场景/角色复用（如本片「图片 5 + 图片 7」组合），但复用必须显式写清。

## 3. 第 2 层：镜头块（Shot）七字段规范

每个 Shot 固定这 7 个字段，**顺序不可变**，缺省字段也要保留标题。

> **两区制提示（§5.1）**：进入交付文件的可复制区时，Shot 块只保留「镜头 / 拍摄内容 / 同期声 / 时长」四个提示词字段；「技巧依据」「备注」属于给人核对的信息，**一律移到说明区**，不进可复制区。

```
Shot NN
镜头：<焦段> <景别>，<景深与焦点>，<运动方式>，<特殊技法>
拍摄内容：<机位坐标> + <环境/光照> + <角色站位> + <动作/表情> + <台词> + <UI/特效>
光影：<可选，仅在偏离全局光照时写>
同期声：<音效清单>
时长：<起>-<止> 秒
备注：<可选，转场 / 首尾帧 / 风险提示>
```

### 3.1 字段 1 · 镜头

**写什么**：四个子项，用「，」分隔。

| 子项 | 必填 | 可选值 |
|---|---|---|
| 虚拟焦段 | ✅ | 24mm（广角张力/低角度仰拍）、**35mm（叙事主焦段，默认）**、50mm（人物中景）、85mm（特写/长焦） |
| 景别 | ✅ | 大全景 / 远景 / 全景 / 中景 / **中近景** / 近景 / 特写 / 大特写 |
| **景深与焦点** | ✅ | 浅景深（写明焦点锁在谁身上，背景虚化）/ 中景深 / 深景深（全景实焦）；可加「焦外光斑」「前景虚化遮挡」等 |
| 运动方式 | ✅ | 固定机位 / 极慢推近 / 推近 / 拉远 / 横移 / 摇（上下）/ 跟拍 / 升降 / 环绕 orbit / 手持 / 慢动作 / crash zoom |
| 特殊技法 | ⭕ | 边角压暗 / 运动模糊 / 定格落版 |

**组合写法**：**一 Shot 只拍一镜**。镜内机位/景别的连续变化用 `→`，同时发生的用 `A + B`；**需要切镜就另开一个 Shot，绝不写在一镜里**。
> 例：`中景，浅景深焦点锁定主角面部，横移→固定机位`
> 例：`大全景，深景深全实焦，缓慢拉远升高定格落版`

### 3.2 字段 2 · 拍摄内容

**写什么**：按 6 个信息槽顺序填，是最长也是最重要的字段。

| 槽位 | 写什么 | 是否必填 |
|---|---|---|
| ① 机位坐标 | **摄影机位于<位置>，距离地面 <X> 米高度，<朝向/拍摄对象>**。必须给数值。 | ✅ |
| ② 环境光照 | 时段 + 天气 + 空间描述 + 光影来源 | ✅ |
| ③ 角色站位 | `@角色 <站位与朝向>`，按画面从前到后/从左到右描述 | ✅（有人物时） |
| ④ 动作表情 | 主体动作 + 微表情；多角色时每个都写 | ✅ |
| ⑤ 台词 | `角色张嘴说："……"`，用中文引号 | ⭕ |
| ⑥ UI/特效 | 系统弹窗、悬浮框、粒子、爆炸等，**UI 文字必须原文照抄** | ⭕ |

**机位高度词典**（写数值时参考）：

| 高度 | 观感 | 典型用法 |
|---|---|---|
| 0.3–0.8 m | 地面低角度广角 | 机甲登场、压迫感、烟尘 |
| 1.5–1.8 m | 平视/人眼 | 对话、对峙、特写 |
| 2.0–3.0 m | 轻微低角度/高机位 | 军帐内景、高台侧拍 |
| 5–15 m | 俯拍 | 江面船队、战场局部 |
| >30 m | 高空俯视 | 城楼全景、战场大全景、落版 |

**切镜规则**：禁止镜内切镜。剧情要换场景 / 换机位时，直接**另开一个 Shot**（编号顺延、时间轴接续），每个 Shot 开头重新写一次机位坐标。上一版 Shot 08 那种「俯拍→中景→平地→低角度→拉远」五连机位，应拆成 5 个 Shot。

### 3.3 字段 3 · 光影（可选）

仅当该镜头的光照**偏离全局模板**时写，一句即可。
> 例：`夜晚火光映亮人物面部，暖橙主光 + 冷月边缘光`

### 3.4 字段 4 · 同期声

**写什么**：分号分隔的音效清单，每类给 1–3 条。

| 类别 | 常见项 |
|---|---|
| 环境音 | 夜风、江风水声、火把噼啪、蚊虫、人声底噪 |
| 动作音 | 拔剑出鞘金属摩擦、船桨划水、推车滚轮、竹简拍打、箭矢破空、爆炸轰鸣 |
| 系统/UI 音 | 系统提示电子音、机械口播声、机甲启动金属音 |
| 人声 | 人物对话声、内心独白、急报声、全军倒吸冷气声 |

**规则**：纯音效还是带 BGM 必须在全局约束里声明一次（本片：纯音效，无 BGM）。

### 3.5 字段 5 · 时长

- 格式：`0-5 秒`（绝对时间轴，不是时长长度）。
- 单镜头时长档位：**3s / 5s / 6s / 10s**，Seedance 单次生成上限内，越短信息越可控。
- 本片为 **8 × 5s = 40s** 均匀分镜，这是买量爽片最稳的节奏。
- 一个时间档装不下（超过 1 个主事件）就**拆成两个 Shot**，编号顺延、总时长顺延，不硬塞。

### 3.6 字段 6 · 备注（可选）

写：转场方式、首尾帧需求、风险提示（如"此镜含二次切镜，建议拆成两段生成"）。

## 4. 字段 → Seedance 实际提示词串的拼装公式

上面的 Shot 块是**脚本格式**；喂给 Seedance 前要拼成**单段提示词**。拼装顺序固定：

```
① 风格前缀（全局核心风格 + 材质）
② 场景锚定（时段 + 空间 + 结构 + 光照）
③ 角色锚定（每个 @角色的五要素）
④ 主体动作与表情（谁在干什么、什么神态）
⑤ 镜头语言（焦段 + 景别 + 机位数值 + 运动）
⑥ 光影与氛围
⑦ 同期声（若开启音频生成）
⑧ 负面约束（全局约束精简版）
```

**Shot 01 拼装示例**（可直接复制跑）：

> 3D 卡通 Q 版次世代国风三国，PBR 材质，电影级游戏 CG。夜晚木质军帐内景，暖黄油灯低位主光，帐门缝隙透入冷月逆光，冷暖硬光对撞。@玩家主角（束发劲装，挺拔张扬）昂首立于帐中央面向镜头放话；@诸葛亮（纶巾羽扇，儒雅）立于左前方，眉头轻蹙、双眼微微睁大、眼神滞了一瞬，双唇微张、嘴角平拉微僵，面部肌肉轻微收紧、表情凝滞错愕；@周瑜（束发都督服佩剑，冷峻）在案桌后拔剑直指主角。虚拟 35mm，中近景，浅景深焦点锁定主角，低角度固定机位（离地 2.4 米），极慢推近。同期声：夜风、拔剑金属摩擦、对话声。禁止：写实人脸、现代物品、多余角色。
>
> 注：脚本与提示词里表情一律「词条名 + 展开描述」双写（见 §5 全局红线），模型不认识词条名。

## 5. 全局约束（负面/红线）

每个项目开工时在全局块下列一次，拼装时精简成 1–2 句带进提示词。

**通用红线**
- 角色造型/配色/道具严格锁定参考图，禁止改配色与造型；
- 无多余人物、无多余物体、无穿帮现代物品（除非剧本明确要求，如 Shot 03 的手机）；
- 无镜头乱晃、无面部扭曲、无肢体畸形；
- **一 Shot 一镜**，禁止镜内切镜；需要切镜一律另开 Shot；
- **表情优先级 + 必须展开（双写规则）**：
  - **表情优先筛选**：从《人物表情描述库》（`outputs/人物表情描述库_v1.md`）的 31 条标准词条里**筛选最贴近的一条**，**严禁自造近义词**；库内确实没有贴合的，标「待确认」并提出沟通，不擅自编造；
  - **【全流程双写】所有交付物（阶段一分镜脚本、阶段二提示词）里，词条名后必须当场展开具体描述**，格式：`表情【极致震惊】——双眼骤然睁大瞪圆、瞳孔收缩；嘴唇微张、嘴角向两侧平拉发僵；面部肌肉僵住、血色略褪`。展开保留「眼部 + 嘴角 + 面部」三个维度（可压成一句连贯中文，但三个维度都要在）。**任何地方都不允许只写【词条名】裸奔**——模型不认词条名，人也不该再手动展开一次；
  - 展开示例：`表情【极致震惊】` → `双眼骤然睁大瞪圆、瞳孔收缩、眼白增多，眉头高挑上扬；嘴唇微张、嘴角向两侧平拉发僵、下颌微垂；额肌收紧抬头纹显现、面部肌肉僵住、血色略褪`。

- **【电影技巧库强制调用】** 镜头语言（运动/景别/焦段/角度/光学/特效）与光影方案**必须从 424 条电影技巧库（`~/.workbuddy/skills/seedance-storyboard-prompt/references/cinematic-techniques.md`）里检索选型**，不得凭感觉造词：
  - 检索：`python references/_tools/search.py <中文意图词/英文关键词> --n 6`，或先查 `references/intent-to-technique.md` 把"压迫感/燃/反转"翻译成词条，再取全文；**禁止整篇 Read 1.3MB 原文**；
  - **每镜至少挂 1 个镜头语言词条**；灯光类镜还要挂灯光类词条；
  - 阶段一脚本里用「技巧依据：<词条中文名>（<English Name>）」字段标注，便于核对；
  - 阶段二提示词里**中英并列嵌入**镜头字段（例：`虚拟 35mm 电影镜头，中近景，浅景深焦点锁定主角，极慢推近 slow push-in（低角度 low angle）`）——模型对英文电影术语响应更稳，库内 Prompt 模板可整段嵌入；
  - 库内确实无贴合词条才自造，并注明「（自造，库内无贴合）」；引用前必扫该词条的「何时不用/常见错误」（少数模板段落是反例）。

**本片专项**
- 纯音效，无 BGM；

### 5.1 【交付两区制 · 2026-09-20 用户投诉定稿】

**用户拿到手的每一个交付文件，必须从物理上分成两个区，中间用显眼分隔线隔开，谁在上谁在下固定不变：**

```
执行参数（模型·画幅·生成档位建议）/ 口播对齐表 / 备注 / 自检清单
```

**可复制区禁入清单（出现即违规）：**
1. 过程性备注与修改痕迹：`（非人角色：无表情词条，参照库内 @XX 先例）`、`（待确认）`、`（自造，库内无贴合）`、`（推断）`、`（已执行/已校验）`等一切解释性括号——非人角色/怪物直接写实际视觉描述（如「双眼绿火骤然点亮、亮度渐强」），说明放说明区「表情词条对照」；
2. 给人的执行建议：`建议按 3s 档生成、后期裁切`、`不够再补 5s 档`、`可从同批素材裁切`——全放说明区「执行参数/备注」；
3. 跨节引用：`（见第三节）`、`见 §X`——提示词里没有「第三节」，模型读不懂；
4. 文件名/路径引用：`（风云助阵_CUT.MP3）`——模型拿不到文件；
5. 技巧依据标注、表情词条来源说明、参考图清单——只住说明区；
6. 库名/词条库名：`参照表情库`、`参照 @关羽机甲 先例`——库是给 Agent 查的，模型不认识。

**阶段一脚本同样执行两区制**：阶段一脚本的可复制区与阶段二提示词正文**逐字一致**（只多「技巧依据」这类核对信息的归属不同——技巧依据只住说明区），说明区放全部核对信息。禁止再出现「五、全局约束 + 执行参数」这种混排节——执行参数里**只有进提示词的负面约束**（如「画面内人物不开口、不做口型；纯音效，无 BGM」），其余（生成档位建议、后期剪辑建议）全在说明区。

## 7. 从粗略剧本 → 提示词：两阶段流程

你发来的通常是很粗略的情节剧本，而且**参考图往往还没生成**。所以固定走两阶段，**先把完整脚本交给你确认，才写提示词**——提示词是直接拿去生成视频的，不能在脚本没定稿时浪费生成额度。

### 阶段一 · 完整分镜脚本（先交付，等你确认）

| 步 | 动作 |
|---|---|
| 1 | 判断/沿用全局风格块（无指定则套默认国风 3D Q 版） |
| 2 | 清点人物 / 场景 / 道具 / 特效，建资产表 → **【资产问询，不许跳过】**问用户：①哪些资产已有图（请传文件路径）；②无图资产要不要我逐个写**生图提示词**。答复后按 §2.2.1 定形态：有图 → 引图锚；无图+要 → 「（无图·文字生图）」行写完整生图提示词；无图+不要 → 纯描述锚。**禁止无图却写「（图片 N：待补）」空引用** |
| 3 | 切分镜头：每 Shot = 一镜 = 1 个主事件；装不下就拆，编号顺延、时间轴接续 |
| 4 | **【查技巧库】**每镜的镜头语言（运动/景别/焦段/角度/光学/特效）**从 424 条电影技巧库检索选型**，脚本里标「技巧依据：<中文名>（<English Name>）」；每镜至少 1 条，无贴合才自造并注明 | 
| 5 | 每镜配：焦段 + 景别 + **景深与焦点** + 运动 + 机位数值（位置 / 高度 / 朝向） |
| 6 | **【查技巧库·灯光】**光照（时段 + 光源 + 方向/光位 + 光质 + 氛围）从技巧库灯光类检索选型，标「技巧依据」；同时写进该镜「环境光照」 | 
| 7 | 站位（画面空间顺序）+ 动作微表情（**表情库 31 条优先筛选，一律双写「词条名——眼部；嘴角；面部」**）+ 台词 |
| 8 | **自检**：全局锁四要素齐、每镜有技巧依据、表情无裸奔词条名、光线实际写进了「环境光照」→ 输出完整脚本，交你确认 |

### 阶段二 · 提示词生成（脚本确认后执行）

| 步 | 动作 |
|---|---|
| 10 | 用户补发资产图后，把对应「（无图·文字生图）」锚定行升级为「（图片 N）」引图锚（描述文字保留），更新锚定表 |
| 11 | 按 §4 公式逐镜拼装；镜头字段**中英并列**嵌入技巧词条（模型对英文术语响应更稳）；开头放唯一一份「【全局锁】」 |
| 12 | 补同期声 + 备注，对照全局约束校验，输出 |

**补全原则**
- 机位必须数值化，不写"合适的位置"；
- 多角色同镜时，站位按画面空间顺序描述，避免模型糊成一团；
- 表情从《人物表情描述库》引用标准词条，不自造近义词；
- **参考图未到位不阻塞阶段一**——占位即可，图到位只做回填；
- 有疑虑写进「备注」，不擅自改剧情。

### §9.1 补充：9:16 竖版构图规则（2026-09-16 实战补录）

竖版横向空间窄，**多人同镜的铁律是「纵深 / 前后排布」，禁止左右横排**（横排必挤、必糊）：

| 场景类型 | 竖版改法 |
|---|---|
| 多人同镜 | 主角占前景画面下 1/3–1/2，配角放左后 / 右后景并虚化；或前后站位（主角前景侧身、反应者后景正面） |
| 大全景（江面/战场/城池） | 改**纵向延伸**：主体自画面下方向上排列至远方，天空或夜空占上 1/3 |
| 低角度大场面 | 前景元素放下 1/3，运动方向**向上出画**（火箭、烟尘、机甲） |
| 上下对峙（城楼 vs 城下） | 三段式：下 1/3 反派仰头 / 中段建筑 / 上 1/3 主角俯视 |
| 落版镜 | 主体占上 2/3，**底部留 1/3 净空给 logo / 文案 / CTA**（竖版留白在下不在上，与横版相反） |
| 系统弹窗 | 统一放人物**下方 / 侧下方**（下 1/3 或胸前位），**永不遮挡面部** |

### §9.2 补充：时长压缩策略（91s → 60s 实战补录）

压时长**不是删镜头，是合并打点**，四招按优先级用：

1. **建立镜并入叙事镜**：大全景建立 + 动作特写 → 合一镜（省 3s/次）；
2. **反应镜用「极慢推近」同镜转折**：A 说狠话 → 镜头推近 B 的崩脸，一镜完成「问 → 打脸」，省一整镜；
3. **一镜打断法**：反派狂言未落，传令兵/噩耗撞入，同机位一镜内完成「哄笑 → 静默」，冲突反而更强；
4. **正反打改同框**：把两个机位的对峙压进一个画面（上下同框 / 前后同框），省一镜且对视关系更直接。

删减优先级（从先砍到后砍）：含蓄爽点（如敌人叹服）> 单纯建立镜 > 重复展示镜 > 二次笑点。**打脸点、最大场面、落版镜永不删。**
