# Seedance 分镜提示词 · 规则卡 v1（2026-09-28）

> 动笔前先读这一张。所有细节以本卡为准，完整规范与技巧库是查阅层，按需翻。

## 八条铁律

1. **一 Shot 一镜**：一个 Shot 只做一件事，切镜另开 Shot，禁止镜内切镜。
2. **机位数值化**：位置 + 离地 N 米 + 朝向，禁止「合适的位置」。
3. **光线进提示词**：全局锁「光线：」行 + 每镜「环境光照」，两处都要有实际文字。
4. **表情双写**：`表情【词条名】——眼部…；嘴角…；面部…`；非人角色直接写视觉描述，不写任何解释括号。
5. **镜头语言出自技巧库**：每镜至少 1 条，中英并列嵌入英文术语。
6. **交付两区制**：可复制区零备注——禁表格、禁文件路径、禁跨节引用、禁执行建议、禁过程备注。
7. **字数上限**：全局锁 + 任一 Shot ≤2000 字（目标 ≤1800），总字符与去空白两口径取严。
8. **每镜必有节奏行与收势定格**（详见下方）。

## 每镜五字段（顺序固定）

```
镜头：<焦段> <景别>，<景深与焦点>，<运动方式>
拍摄内容：<机位坐标> + <环境光照> + <角色站位> + <动作/表情> + <台词> + <UI/特效>
节奏：<节拍句，见下>
同期声：<音效 3–5 条>
时长：<起>-<止> 秒
```

## 节拍句格式（必写）

```
节奏：0.0-0.5s 静态起幅（人物静止，仅火光与尘埃缓慢浮动）；0.5-2.4s 单一动作（拔剑出鞘一次完成）；2.4-3.0s 收势定格（动作完全停止，画面静止持续到最后一帧，holds still for the final frames）
```

- **三段之和必须等于该镜「时长」字段的值，误差 0**
- 起幅段 ≥0.3s（≥3s 的长镜 ≥0.5s），收势段 ≥0.3s，**缺其一即违规**
- 收势段必须中英并列写死「画面静止持续到最后一帧 / holds still for the final frames」
- 中间动作段写动作本身，不写形容词堆砌

## 动作配额（超了就拆镜，不许硬塞）

| 镜长 | 允许主动作数 | 起幅 | 收势 |
|---|---|---|---|
| ≤1.5s | 0–1 个（纯氛围镜可为 0） | ≥0.3s | ≥0.3s |
| 1.5–2.5s | 1 个 | ≥0.3s | ≥0.3s |
| 2.5–4s | ≤2 个 | ≥0.4s | ≥0.4s |
| 4–5s | ≤3 个 | ≥0.5s | ≥0.5s |

## 生成档位映射（平台只有 5s / 10s 死档）

| 目标时长 | 用什么档 | 提示词里怎么写 |
|---|---|---|
| ≤2.4s | 5s 档生成，后期裁前 Xs | 动作必须在前 X 秒内完成，其后画面完全静止并保持到片段末尾 |
| 2.5–5s | 5s 档铺满 | 节拍铺满全镜，尾部仍留 ≥0.4s 静止收势 |
| 5–10s | 10s 档 | 起幅 / 发展 / 收势三段，各段都标秒数 |

## 全局锁（全文只写一次，放最开头）

风格 / 基调 / 色调 / 光线 / 资产锚定（**有图引图（图片 N），无图直接写完整生图提示词，禁止「待补」空引用**）/ 负面约束。

## 交付前必过（贴在说明区）

- [ ] Σ 各镜时长 = 目标总时长 ±0.5s，说明区有时长预算表
- [ ] 每镜有节奏行，且节拍分段之和 = 该镜时长
- [ ] 每镜收势定格，写了「静止持续到最后一帧」
- [ ] 字数自检通过（附逐 Shot 字数表）
- [ ] **复述一行**：全片 N 镜 / 总 XX.Xs（目标 XX.Xs）；最长镜 Xs、最短镜 Xs；每镜已写节拍句与收势定格；短镜已标生成档位与裁切点。
