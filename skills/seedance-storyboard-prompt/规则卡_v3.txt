# Seedance 分镜提示词 · 规则卡 v3（2026-09-28）

> 动笔前先读这一张。所有细节以本卡为准，完整规范与技巧库是查阅层，按需翻。
> v3 修订：**时间线提到 Shot 标题行**；**取消独立「节奏：」字段**，节拍按时间顺序并进「拍摄内容」开头；字段由五个减为三个。

## 九条铁律

1. **一 Shot 一镜**：一个 Shot 只做一件事，切镜另开 Shot，禁止镜内切镜。
2. **机位数值化**：位置 + 离地 N 米 + 朝向，禁止「合适的位置」。
3. **光线进提示词**：全局锁「光线：」行 + 每镜「环境光照」，两处都要有实际文字。
4. **表情双写**：`表情【词条名】——眼部…；嘴角…；面部…`；非人角色直接写视觉描述，不写任何解释括号。
5. **镜头语言出自技巧库**：每镜至少 1 条，中英并列嵌入英文术语。
6. **交付两区制**：可复制区零备注——禁表格、禁文件路径、禁跨节引用、禁执行建议、禁过程备注。
7. **字数上限**：全局锁 + 任一 Shot ≤2000 字（目标 ≤1800），总字符与去空白两口径取严。
8. **时序内嵌 + 静止到末帧**（见下）：时间线住标题行，节拍并进「拍摄内容」开头，禁止亚秒数。
9. **镜长与镜数预算**（见下）：单镜 ≥1.5s，镜数 ≈ 总时长 ÷ 2.0，切太碎等于没节奏。

## 每镜结构（标题行时间段 + 三字段）

```
Shot 04｜00:04.8-00:06.8（1.6 秒）
镜头：<焦段> <景别>，<景深与焦点>，<运动方式>
拍摄内容：时序 0.0-0.5s <起幅>；0.5-1.5s <主体动作>，一气呵成做完即停；1.5-5.0s 画面完全静止、无任何运动，持续到最后一帧 / holds still for the final frames。｜<机位> + <环境光照> + <站位> + <表情> + <台词> + <UI/特效>
同期声：<音效 3–5 条>
```

- **绝对时间段只在 Shot 标题行写一次**，正文不再重复；标题行必须与说明区「时长预算表」逐镜一致。
- **时序段放在「拍摄内容」最前面**，用 `｜` 与后面的场景描述隔开——放到后面会被长长的机位/光照/表情描述淹没，等于没写。
- 正文只写**这一镜独有的东西**。全局负面约束（无第四人、禁止第一人称、无现代穿帮物等）只在全局锁写一次，禁止逐镜复述。

## 时序段写法（必写，v3 改法）

格式：`0.0-<a>s 起幅 → <a>-<X>s 主体动作 → <X>-<档位总长>s 完全静止`

```
拍摄内容：时序 0.0-0.5s 人物静止，仅火光与尘埃缓慢浮动；0.5-2.0s 拔剑出鞘一次完成，
一气呵成做完即停；2.0-5.0s 画面完全静止、无任何运动，持续到最后一帧 / holds still for the final frames。｜摄影机位于……
```

- **秒数一律 0.5s 粒度**（0.5 / 1.0 / 1.5 / 2.0…），**禁止 0.15 / 0.45 / 0.6 / 0.8 这类非 0.5 倍数的秒数**——视频扩散模型没有亚秒级时间分辨率，只认「开头 → 中间 → 结尾」，写细了是噪声、还稀释真正的动作描述。
- **段与段首尾相接、从 0.0s 起、无缝隙**。
- **动作段必须加「一气呵成做完即停」**——这是区间写法的必备解药：只写 `0.5-2.0s 动作`，模型会理解成「动作要撑满这一段」；补这一句把语义扭回**完成点**（2.0s 前做完，做完就停，不许慢放铺满）。
- **末段止点写死生成档位总长**（5s 档 = `5.0s`），等于顺手告诉模型「这段片段一共 5 秒」——这是防止尾部加戏最有效的一句。只写「保持到片段末尾」等于没说末尾是第几秒。
- 末段必须**中英并列**写死「画面完全静止、无任何运动，持续到最后一帧 / holds still for the final frames」。
- 起幅 ≥0.3s；收势（**镜长 − 动作完成点 X**）≥0.3s——动作必须在交付镜长结束前 0.3s 以上做完。
- **时序里的秒数是「生成档内的时间」，不是交付时长**：镜长 1.6s 的镜写 `1.0-5.0s 完全静止`，含义是「5s 档从第 1.0 秒起不动」，实际裁到 1.6s。执行参数（按 5s 档生成 / 裁前几秒）写说明区，**不进可复制区**。

## 镜长与镜数预算

| 单镜目标时长 | 判定 | 生成方式 |
|---|---|---|
| < 1.5s | **禁止**，必须并入相邻镜 | — |
| 1.5–2.0s | 下限区，仅在快剪段落使用 | 5s 档，裁前 1.5–2.0s |
| 2.0–4.0s | **推荐区间** | 5s 档，尾部留静止 |
| 4.0–5.0s | 5s 档铺满 | 5s 档 |
| 5.0–10s | 拆起幅 / 发展 / 收势三段 | 10s 档 |

**镜数 ≈ 总时长 ÷ 2.0（允许 ±2）**：15s → 6–9 镜｜30s → 13–17 镜｜60s → 25–35 镜。
镜数超出上限就是切太碎，先合并再写。

**同构镜合并检测**：连续 3 镜以上机位相同、动作相同、只换环境元素（地面材质 / 背景物件）→ 必须合并成 1–2 镜，靠**元素在一镜内递变**体现推进（如「水泥 → 沙 → 泥，越拍越慢」写在一镜里），不要靠五个几乎一样的短镜。

## 动作配额（超了就拆镜，不许硬塞）

| 镜长 | 允许主动作数 | 起幅 | 收势 |
|---|---|---|---|
| ≤1.5s | 0–1 个（纯氛围镜可为 0） | ≥0.3s | ≥0.3s |
| 1.5–2.5s | 1 个 | ≥0.3s | ≥0.3s |
| 2.5–4s | ≤2 个 | ≥0.4s | ≥0.4s |
| 4–5s | ≤3 个 | ≥0.5s | ≥0.5s |

## 生成档位映射（平台只有 5s / 10s 死档）

| 目标时长 | 用什么档 | 时序段里怎么写 |
|---|---|---|
| ≤2.4s | 5s 档生成，后期裁前 Xs | 动作在片段前 Xs 内完成，其后静止到 5.0s（末段写 X-5.0s） |
| 2.5–5s | 5s 档铺满 | 时序铺满全镜，末段留 ≥0.4s 静止 |
| 5–10s | 10s 档 | 起幅 / 发展 / 收势三段，各段都标秒数 |

## 全局锁（全文只写一次，放最开头）

风格 / 基调 / 色调 / 光线 / 资产锚定（**有图引图（图片 N），无图直接写完整生图提示词，禁止「待补」空引用**）/ 负面约束。
