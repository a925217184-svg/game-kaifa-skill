执行要求：
1. 先走阶段零（想法粗时给技巧选型提案）→ 阶段一分镜脚本 → 我确认后 → 阶段二提示词；15 秒以内的口播广告可两阶段一起交付。
2. 每个交付文件严格分「可复制区 / 说明区」两区，可复制区内不许出现备注、修改痕迹、执行建议、跨节引用、文件路径、库名引用。
3. 每镜的镜头语言与灯光都要标出「技巧依据：<中文名>（<English Name>）」，提示词里中英并列嵌入英文术语。
4. 表情一律「表情【词条名】——眼部…；嘴角…；面部…」双写，禁止只写词条名。
5. 交付前跑一遍规范第 7 节的自检清单，并把它贴在说明区末尾。
6. 打斗场景额外自检：逐镜字段序合规 → 每处打击五件套齐且带触点标记词 → 场景层已预声明可破坏性 → 上一镜的破坏痕迹在本镜「开局站位状态」里被继承。
7. **字数硬限制**：Seedance 单次提交上限 2000 字，计量单位是「全局锁 + 目标 Shot 正文」这一段。请控制在 ≤1800 字（硬上限 2000），全局锁预算 ≤900 字、每镜正文 ≤1100 字。写完后请逐段数一遍字符数，并在说明区附一张「逐 Shot 字数 / 是否超限」的表；超限就按规范 6.1 的顺序压缩（先压全局锁 → 再压正文次要修饰 → 同期声留 3–5 条 → 仍超就拆镜），但绝不能删表情三维度、机位数值、景深焦点、环境光照和弹窗原文。
8. **时长必须落到每一秒，不是挂个标签**（这是最容易出错的一条）：
   - **先卡镜数和镜长，再写节拍句**：单镜目标时长 **<1.5s 一律禁止、必须合并**；镜数 ≈ 总时长 ÷ 2.0（±2），15s→6–9 镜、30s→13–17 镜、60s→25–35 镜。别把片子切太碎——平台最短档是 5 秒，你要求「动 0.6 秒、静止 4.4 秒」模型做不到，它会把动作铺满 5 秒，结果是裁了只剩起手式、不裁总时长翻倍。这是「AI 不按时长出片」的头号原因；
   - **连续 3 镜以上机位相同、动作相同、只换环境元素（地面材质/背景物件）→ 必须合并成 1–2 镜**，用「元素在一镜内递变 + 速度力度递变」体现推进，不要靠一堆几乎一样的短镜；
   - 切完镜先出「时长预算表」（Shot / 目标时长 / 生成档位 / 累计时长），Σ 各镜 = 我要的总时长 ±0.5s；
   - **时间线写进 Shot 标题行**（不要挂在 Shot 末尾）：`Shot 04｜00:04.8-00:06.8（1.6 秒）`——绝对时间段放在第一行，我读第一眼就知道这一镜在整片的哪一段、多长；
   - **节拍不要单独占一个字段，也不要写成一整块再拼描述**——把「什么时间做什么」**穿插进「拍摄内容」的句流里**：机位与光照起句（恒定信息不挂时间），随后 `0.0-0.5s <起幅>。0.5-1.5s <主体动作>，一气呵成做完即停；1.5-5.0s 画面完全静止、无任何运动，持续到最后一帧 / holds still for the final frames。`，站位、表情、台词挂在它对应的那个时刻上。整镜只有三个字段（镜头 / 拍摄内容 / 同期声），越短越直白越好。**反面教材**：`拍摄内容：时序 0.0-0.5s …；0.5-1.5s …；1.5-5.0s 完全静止…。｜摄影机位于……` ——把节拍整段贴进正文、再用 `｜` 与其余内容切开，等于「节拍块 + 描述块」两块拼接，我不要这种；
   - **不要出现「时序」这两个字**；时间标记按时间顺序出现、首尾相接、从 0.0s 起、段与段之间不许有缝；
   - **写出的秒数只取 0.5s 粒度**（0.5/1.0/1.5/2.0…），**禁止 0.15s、0.45s、0.6s、0.8s 这类非 0.5 倍数**——模型没有亚秒分辨率，写了只是噪声；
   - **末段止点写死生成档位总长**（5s 档就写 `5.0s`）：`1.5-5.0s 画面完全静止…`。只写「保持到片段末尾」等于没说末尾是第几秒，模型不会给你留静止；末段同时**中英并列写死「画面完全静止、无任何运动，持续到最后一帧 / holds still for the final frames」**——没有这句，模型会在尾部继续加戏，我没法精准裁切；
   - **动作段必须补一句「一气呵成做完即停」**：`0.5-1.5s 拍地三下，一气呵成做完即停`。只写区间不写这句，模型会把动作铺满整个窗口，而不是「1.5s 前做完」；
   - **时间标记里的秒数是「生成档内的时间」，不是交付时长**：镜长 1.6s 的镜照样写 `1.0-5.0s 完全静止`，实际裁到 1.6s。执行参数（按几秒档生成、裁前几秒）写在说明区，**不要写进可复制区**；
   - 起幅 ≥0.3s、收势（镜长 − 动作完成点 X）≥0.3s——动作必须在交付镜长结束前 0.3s 以上做完；
   - 主动作数按配额：≤1.5s 限 0–1 个、1.5–2.5s 限 1 个、2.5–4s 限 2 个、4–5s 限 3 个，超了就拆镜，不许把动作堆在同一镜里压缩描述；
   - **正文只写这一镜独有的信息**：「无第四人」「禁止第一人称」这类全局负面约束只在全局锁写一次，严禁逐镜复述；
   - 说明区必须写一行时长核对：「全片 N 镜 / 总 XX.Xs（目标 XX.Xs）；最长镜 Xs、最短镜 Xs；每镜标题行带时间段、时间标记穿插在正文句流里且秒数全为 0.5s 粒度、按时间顺序首尾相接；末段止点 = 档位总长、含「静止到最后一帧」；反算收势（镜长 − X）≥0.3s；短镜已标生成档位与裁切点」。
