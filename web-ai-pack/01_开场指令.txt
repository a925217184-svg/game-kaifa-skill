请你先完整读一遍规则卡，然后严格遵守它执行，不要凭感觉自由发挥、不要跳步。

（这份规则卡是按官方《即梦 Seedance 2.0 使用手册》全文提炼的，**写法以官方为准**。我如果还给了你别的旧版规范文件，内容冲突时一律以规则卡为准；你每次动笔前先读它，交付前按它的自查清单核一遍。）

（如果本次剧情涉及打斗 / 战斗 / 对决 / 追杀 / BOSS 战，我会额外给你一份《打斗提示词参考手册》。打斗场景内以它为准，但**写法形态仍按规则卡**：一段自然语言 + 整数秒时间线，不许退回字段表。）

我的需求：
- 剧情 / 想法：
- 想要的感觉：（不填就按剧情推断并标注「推断」）
- 风格：（不填默认写实电影质感；**真人实拍还是 3D/动画请先问我，别默认套 3D 卡通**）
- 总时长：（不填默认 15 秒）
- 画幅：（不填默认 9:16 竖版）
- 参考图：（我会贴图；没图的资产请你先问我：要不要为每个资产写生图提示词）

执行要求：

1. 先走阶段零（想法粗时给 2-3 个镜头语言候选）→ 阶段一分镜脚本 → 我确认后 → 阶段二提示词；15 秒以内的口播广告可两阶段一起交付。
2. 每个交付文件严格分「可复制区 / 说明区」两区，可复制区内不许出现备注、修改痕迹、执行建议、跨节引用、文件路径、库名引用。
3. **一条 prompt = 一段自然语言**，不分字段、不打标签。禁止「镜头：/ 拍摄内容：/ 同期声：」这类表格体——官方手册里没有任何一条案例是这么写的。
4. 每条以【第 N 条 · 生成时长选 X 秒】开头，X 在 4-15 之间。**想要几秒就选几秒**（官方 4-15s 自由选择），不许写「按 5 秒档生成、只取前 X 秒」。
5. 时间线用 `0-3秒画面：…` `3-5秒画面：…`：整数秒、从 0 起、段与段首尾相接、末段止点 = 该条生成时长。**一条就能出 15 秒、内含 4-5 个分镜**；快节奏用「快速闪切 / 快速切换 / 依次定格」写在一条里，**不是靠生成更多条**。
6. **字数上限 2000 字**（官方 2026-09-29 更新）。官方案例 80-250 字是「够用就停」的示范，不是天花板——该写细就写细，但**每一句都要为画面付费**：新增的文字必须对应画面上真实可见的东西（环境材质 / 光影 / 表情 / 动作细节 / 声音）。**不许堆同义形容词、不许把同一件事换三种说法**——那是稀释注意力，不是增强。
7. 角色用 `@图片N` 锚定一次，后文统一叫「主体1 / 主体2 / 主体3」，前后不要混用角色名。
8. 景别运镜 / 动作 / 情绪 / 台词混写在句子里，不单列：情绪 `（情绪：恐慌、窒息）`，台词 `大喊："杰哥！不要啊！"`，画面内的字 `字幕弹出"再忙也要记得吃点零食~"`。
9. **换过环境就得切回来**（最容易漏）：时间线里一旦快切离开主场景，回到主场景那段必须写 ①「切回XX」② 主体当前姿势（仍躺 / 仍被压 / 仍蹲）。漏了前者，后半场会接在最后一个快切场景里；漏了后者，躺着的人会自己站起来。
10. 每条结尾一句「整体…」打包：色调 + 光影 + 节奏 + 声音 + 排除项。排除项写进这一句里，不单列负面词表。
11. 交付前按规则卡第五节清单自查并贴在说明区末尾；本地能跑脚本就跑 `python check_beats.py <文件.txt> --total <总秒数>`（退出码非 0 就是有违规）。

已废止的旧写法（见到即删）：三字段结构（镜头/拍摄内容/同期声）、Shot 标题行 `00:04.8-00:06.8（1.6 秒）`、「时序 …｜…」这种节拍块 + 描述块拼接、0.5s 粒度与亚秒数、「一气呵成做完即停」、「画面完全静止持续到最后一帧 / holds still for the final frames」（仅做首尾帧循环视频时保留）、「按 5 秒档生成/只取前 X 秒」、「X + Y = 5」、机位必须写「离地 X 米」数值、每镜复述全局负面约束、表情库三维度强制双写。
