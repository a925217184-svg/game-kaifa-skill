# 05 · 打斗提示词参考手册（网页 AI 自包含版）

> 本文件是《Seedance 分镜提示词规范》的**打斗场景专用补充**，与主文件 `02_网页AI规范_完整自包含版.md` 配套使用。

## 一、什么时候要用它

满足任意一条，就必须读本文件再动笔：

- 剧情里有 打斗 / 战斗 / 交手 / 对决 / 搏杀 / 追杀 / 群战 / 怪物搏杀 / BOSS 战；
- 用户提了「炫酷打斗 / 强化打击感 / 丰富特效 / 动作不流畅 / 打击没力度 / 节奏拖沓」这类需求词；
- 提示词里出现 兵器碰撞、能量对轰、变身觉醒后的战斗段落。

## 二、它和主规范怎么配合

| 层面 | 归谁管 |
|---|---|
| 全局锁、Shot 字段、两区制、字数上限、表情双写 | **主规范（02）**，一律照它 |
| 打斗内部的字段顺序、打击反馈、环境破坏、力量分级 | **本手册**，逐镜落 |
| 单镜的镜头语言 / 灯光词条选型 | 主规范第 5 节的 424 条技巧库 |

冲突时：**打斗场景内以本手册为准，其余一律以主规范为准。**

## 三、执行要求（写给 AI）

1. 逐镜固定字段序：`开局站位状态 → 镜头 → 动作 → 台词 → 情绪 → 特效 → 声音（前景/背景）`，不得跳序；
2. 每一处打击必须凑齐「接触闪 / 形变 / 位移 follow-through / 反作用力 / 二次破坏」五件，并配一个触点标记词（黑白闪 / 顿帧 / 音爆 / 震屏）；
3. 环境破坏走四段式：**场景层先预声明可破坏性 → 交手产生破坏 → 跨镜留残留痕迹 → 环境持续运动不停帧**；
4. 用户提需求词时，按 §5.1 映射表**取模块改字段**，不要重写全篇；
5. 本手册的所有产出同样受主规范的字数硬限制约束（「全局锁 + 目标 Shot」≤1800 字，硬上限 2000）。

### 1.2 七层职责对照（本手册统一口径）

| # | 层 | 载体 | 必须写清 | 禁止 |
|---|---|---|---|---|
| 1 | **风格约束** | 【视频基础】【光影质感】 | 画幅、渲染级别、构图法则、景深策略、2:8 光影配比、**冷暖对冲色对**、全片特效总清单 | 逐镜重复全片设定 |
| 2 | **场景设定** | 【世界背景通用】【场景与环境】 | 空间结构、材质、**可破坏性**、持续环境运动（风/尘/粒子）、「适合……」功能句 | 只写静态外观不写交互潜力 |
| 3 | **机位与运镜** | 标题行 + `镜头：`行 | 时长数值、景别、机位数值（离地 X 米/焦段 mm）、运动动词、起止景别 | 用「镜头感很强」等感受词 |
| 4 | **动作编排** | `动作：`行 | 蓄力 → 爆发 → 位移 → 落地/结果，一镜一条完整事件链 | 一镜内塞两个独立事件（需拆镜） |
| 5 | **特效表现** | `特效：`行 | 只写可见元素：粒子、流光、拖尾、闪白、扭曲、遮屏 | 把「他很愤怒」写进特效行 |
| 6 | **打击反馈** | `动作：`行尾部 + `特效：`行 + `声音：`前景轨 | 受力三件套：**形变 / 反作用力 / 二次破坏** + 触点标记（黑白闪、音爆、震屏） | 只写「打中了」不写被打成什么样 |
| 7 | **节奏与氛围** | 时长标签队列 + `声音：`分层 + `情绪：`行 | 长短帧交替、前景/背景声音分层、单镜一个情绪词 | 全片统一帧长（必然拖沓） |

### 1.3 分镜字段规范（固定顺序，不得跳序）

```
【XS】<景别+机位+运镜>・<一句话画面钩子，写到「发生了什么」为止>
开局站位状态：<谁在哪 / 上一个状态的结果 / 本镜起手前的人在做什么>
镜头：<时长数值 机位 景别 运动方式 起止变化 特殊光学>
动作：<蓄力 → 触发 → 主体运动轨迹 → 对手反应 → 结果状态，一条因果链>
台词：<角色名（语气/情绪）：内容>   // 无则写「台词：无」
情绪：<1 个词 + 一句状态，仅关键镜出现>   // 可选字段
特效：<光/粒子/流光/扭曲/遮屏，逗号分隔，不写情绪不写剧情>
声音：前景：<近距离、有源、Per-shot>；背景：<环境层、低频层>
```

**标题行公式**：`时长 + 机位 + 一句话钩子`，钩子用「・」连接，不写句号。
原句式示例：
- `2S 大角度倾斜仰拍・烟雾之中江寻背面，五指张开召唤武器，极远之处街道战刀震动腾飞旋转飞出`
- `2S 希区柯克变焦・超级大透视蓄力蹬地，楼房塌陷`
- `0.5S 全屏紫色闪电高速突进`
- `30S 连续镜头 全景至多机位交替，破败高楼废墟内部两人超高速混战`

## §2 技巧提炼

### 2.1 时序与节奏

**① 时长数值写在开头**，作为节拍单位，不接受模糊词（「片刻」「须臾」）。
```
标准帧谱：0.5S（冲刺/命中脉冲） → 1S（蓄力/反应） → 2S（常规动作）
        → 3S（变身/释放） → 4~6S（结果展示） → 30S（多机位连打段）
```

**② 脉冲型帧序**：短帧堆叠后再给一个长帧泄压，制造「快—快—停」重音。
```
原句帧序：0.5S 全屏紫色闪电高速突进 → 0.5S 斩击命中，黑白强光闪烁 → 6S 仰拍镜头，妖兽受斩，头身分离
```

**③ 镜内变速（Speed Ramp）**：慢镜嵌在镜中段，落地后回原速，不做整段慢镜。
```
原句：「2S中景侧拍，中段进入慢镜头，之后切回正常速度」
      「2S慢镜头后切回正常播放速度，挥刀」
写法：<时长> <景别> <机位>，中段切入慢镜头，<慢放内容>，随后恢复常速，<结果>
```

**④ 极停定格**：所有环境运动骤停，用静止反衬打击（Freeze Frame 级）。
```
原句：「狂风瞬间全部骤停，江寻头发、衣摆抖动骤然静止，极强急停定格效果」
```

**⑤ 蓄力—爆发双段结构**：蓄力必须给独立时长，不可与爆发同帧。
```
蓄力模板：<身体部位>下蹲 / <躯体部件>收拢 / <外物>向周身聚拢，<时长>S，
          「力量积蓄至顶点之后……猛地……」
```

**⑥ 长段落用连续镜装订**：一段高强度混战用一个 `XS 连续镜头` 统摄，内部拆成编号列表（1）…（17）），每段仍须写清机位与受力动静，事件链连续不断。

**⑦ 台词当节拍器**：一句重复台词贯穿多个短镜，撑住节奏不散。
```
原句：「妖兽（连续嘶吼）：可恶，可恶，可恶，可恨的人类！」贯穿 6 镜变身段落
```

### 2.2 镜头语言

| 手法 | 用法 | 套用句式 |
|---|---|---|
| 大透视 / 近大远小 | 24mm 贴近主体，前景占满 | `<焦段>mm 摄像机贴近主体，强化近大远小透视，空间向远方快速拉伸` |
| 希区柯克变焦（Dolly Zoom） | 蓄力顶点 / 情绪翻转 | `希区柯克变焦，镜头产生剧烈透视变化，整个镜头被<主体>占满` |
| 的主体占满画面 | 力量宣示 / 特写打击点 | `超大透视一脚踹出，画面几乎被<部位>占满` |
| 环绕推进（Orbit In） | 变身 / 大招起手 | `<时长>S 环绕运镜，从背面俯视环绕推进，最终切至正面全景` |
| 跟拍 / 摇镜跟拍（Tracking / Pan Follow） | 高速位移可读性 | `镜头不停切换倾斜角度，追踪两人高速交手` |
| 多机位无缝切换（Multi-cam Cut） | 连打段 | `多镜头无缝切换，全景、中景、近景交替` |
| 主观视角（POV） | 死亡/坠落/被击中瞬间 | `<角色>头部主观第一视角，向后仰倒从高空掉落仰拍后拉镜头` |
| 前景遮挡（Foreground Occlusion） | 增加纵深与速度感 | `前景不断划过断裂承重柱、飞溅碎石遮挡画面` |
| 倾斜构图（Dutch Angle） | 常态不稳感 | `大角度倾斜仰拍 / 倾斜角度中景` |
| 第一人称 Muscle Cam | 只露手部，强化操作感 | `镜头跟拍<角色>第一视角，画面内只有<部位>的画面` |

> 运镜不叠加超过 2 个动词；叠加必写清顺序（先……随后……）。

### 2.3 受力反馈 · 打击感五件套（缺一即无手感）

| # | 件 | 定义 | 原句范例 |
|---|---|---|---|
| 1 | **接触闪** | 命中瞬间的高光/闪白/粒子爆 | `击中位置爆发一圈冲击气浪，黑白闪爆闪` |
| 2 | **形变** | 受力部位的挤压、凹陷、撕裂 | `回旋踢实实在在踢中妖兽躯体，巨大冲击力作用在妖兽身上` |
| 3 | **位移（follow-through）** | 被打者的后续运动必须完整演完 | `妖兽整个身躯向后剧烈倒飞，直接飞出镜头画框` |
| 4 | **反作用力** | 施加者的反动 / 自身支点被破坏 | `蹬地瞬间地表被蹬裂` / `刀刺入的力道掀飞了妖兽身后的废墟` |
| 5 | **二次破坏** | 力量溢出到环境，用「贯穿层数 / 崩塌范围」量化 | `连续贯穿坠落五层楼体，层层楼板被砸穿` |

**触点标记词（必配其一）**：`黑白闪`、`顿帧`、`音爆`、`震屏（震动屏幕）`、`高对比闪白（High-contrast Flash）`。
```
原句：战刀因为被踢击得原因瞬间飞出镜头，激起一整音爆
原句：江寻高高跃起，特写展示全力向下挥刀猛劈，形成巨大圆形冲击波，妖兽被巨大斩击力量狠狠劈向楼层下方
```

**伤害可视化三件套**（决定「疼不疼」）：
```
① 伤口持续：伤口不断溢出<色>血雾粒子 / 流淌暗红血色粒子
② 生理反应：面部肌肉紧绷 / 瞳孔红光剧烈放大 / 倒抽冷气
③ 行为代价：单手死死捂住伤口 / 需撑地才勉强站稳 / 攻击距离明显变短
```

### 2.4 环境交互 · 四段式

```
① 预声明可破坏性（写在场景层，不是写在动作里）
   「墙体脆弱易崩塌、承重柱可被直接击毁」
② 交手产生破坏（写在动作/特效行）
   「每一次交手都爆发爆炸与浓密烟雾」
③ 破坏留下痕迹（跨镜延续，不做一次性的）
   「每一拳砸落地面都向外溅起碎石尘土……每一击都加重地面破坏痕迹」
④ 环境持续运动（环境永不停帧）
   「全程持续强狂风，沙尘、碎纸屑、废墟碎屑被狂风不断卷动飞舞」
```

> 关键：**先宣称能碎，才允许碎**。场景层没有预声明的可破坏性 = 生成时的结构抖动。

### 2.5 力量层级与代价感

**力量阶梯（四档，逐级抬高，不得跳）**
```
L1 常规交手 ── 连打 / 能量碰撞 / 硝烟                 （对手可承受）
L2 重击 ──── 形变 + 位移 + 大面积二次破坏      （对手受伤失位）
L3 觉醒/变身 ── 全身外观改写 + 阶段性粒子演出（改变角色强度定位）
L4 终结一击 ── 环境全部静止 + 延时揭示 + 分离/贯穿（不可逆结果）
```

**代价感写法（不写代价 = 无力量感）**
```
① 外观代价：黑发 → 纯白长发；普通形态 → 8.8 米终焉形态；正常 → 全身血色熔岩裂隙纹路
② 环境代价：整栋楼层受冲击彻底塌陷崩毁 / 城市大范围连环爆炸火光冲天
③ 时间代价：台词倒计时「只要再过40秒！」
④ 仪式代价：终结前让世界静止（狂风骤停、慢呼吸、背景纯黑）——让整场空间为这一刀让路
⑤ 轻描淡写代价：杀招只用单手（另一只手插兜满脸笑容）——压迫感来自不费力
```

### 3.1 运镜

```
景别：大全景 / 全景 / 中全景 / 中景 / 中近景 / 近景 / 特写 / 大特写 / 面部特写 / 手部特写 / 全身特写 / 超远景 / 超大全景远景
```

## §5 调用规则

### 5.1 需求词 → 模块映射

| 用户说 | 优先取用 | 必改字段 | 不动字段 |
|---|---|---|---|
| **炫酷打斗 / 不够炸 / 场面不够大** | §2.2 镜头语言 + §3.1 运镜 + §3.4 特效 + §3.5 环境破坏 | 镜头行的运动动词与特殊光学；特效行叠加 2~3 种可见效果 | 动作因果链不删 |
| **强化打击感 / 打的不疼 / 没手感** | §2.3 打击感五件套 + §3.3 打击感 | 补齐「接触闪 / 形变 / 位移 / 反作用力 / 二次破坏」五项；加触点标记词；加伤害可视化三件套 | 不加新动作，只补反馈 |
| **丰富特效 / 特效单调** | §3.4 特效 + §2.4①② | 特效行按「能量 / 拖尾 / 残像 / 变形 / 覆盖」各取其一 | 动作行不动 |
| **动作不流畅 / 卡断 / 一块块的** | §2.1 时序节奏（尤其①时长数值 ③镜内变速）+ §3.2 动作流畅度 | 给每镜补精确时长；拆「一镜两事件」；加衔接句；慢镜改镜内变速 | 不一味加时长数值更大的镜 |
| **力量感不足 / 不出力** | §2.5 力量阶梯 + §2.3 第 5 件二次破坏 + §3.5 贯穿/整合句 | 用「贯穿 X 层 / 塌陷 X 米 / 撞穿 X」量化；插入 L3 觉醒模块（§4.4） | 不靠加大粒子尺寸 |
| **缺少代价感 / 一拳就赢太轻松** | §2.5 代价感五条 | 补外观代价 / 环境代价 / 时间代价 / 仪式代价之一 | 不加冗长的受挫过程 |
| **节奏拖沓 / 太慢** | §2.1 ②脉冲帧序 + §1.2 第 7 层 | 拆长镜为 0.5~2S 短帧；补密集的机位切换 | 不删结果展示长帧 |
| **环境太干净 / 不够脏** | §2.4 环境交互四段式 + §3.5 持续/痕迹 | 场景层补可破坏性预声明；补持续环境运动；补跨镜残留痕迹 | 不在终结镜临时加破坏 |
| **看得不清 / 不知道谁打了谁** | §2.2 跟拍/前景遮挡 + §1.3 开局站位状态 | 每镜补齐开局站位状态；改「轴向/纵向」排布；降低同屏信息密度 | 不降密度，只降混淆 |
| **想要第一人称操作感** | §2.2 主观视角 + Muscle Cam + §3.1 特殊 | 加 POV/主观第一视角，或只露手部的第一人称镜 | 不变全局画幅 |
| **想要悬念式收尾** | §2.1 ④极停定格 + §2.5 仪式代价 + §4.4 收尾模块 | 终结前让世界静止、背景转纯黑、加延时揭示（Delayed Reveal） | 不在同一镜加第二处黑白闪 |

### 5.2 症状 → 诊断 → 修正（逐条查）

| 症状 | 根因 | 修正动作 |
|---|---|---|
| 打击像「碰到」不像「打到」 | 缺位移 + 缺反作用力 | 动作收尾补 follow-through（打完之后的故事），结尾加「对手背后的废墟被这一下掀飞 / 地表被蹬裂」 |
| 画面只剩一团光效，看不出谁在发力 | 特效行抢了动作行的戏 | 把「他很用力」从特效行挪回动作行；特效行只留可见元素 |
| 冲击炸开后，下一镜环境又恢复原状 | 破坏一次性，未跨镜延续 | 场景层写「每一击都加重破坏痕迹」，下一条 `开局站位状态` 继承破坏结果 |
| 角色位置失忆，攻防方向漂移 | 缺开局站位状态 | 每镜首字段写清「谁在哪、上一镜结果」 |
| 慢镜出现人物形变 、五官崩坏 | 整段慢镜 + 大动作 | 改 Speed Ramp：中段慢、落地回原速、慢镜段避免多段位移 |
| 建筑塌了但角色五官也跟着变 | 缺负面约束 | §3.7 追加一致性约束行 |
| 长段落糊成一团、事件丢失 | 30S 连续镜承载过多事件 | 内部编号拆 8~12 段小事件，每段独立配动静与声音 |

### 5.3 冲突时的取舍优先级

```
字数/注意力预算不够时，按此顺序保留，从后往前砍：
① 开局站位状态 + 时长数值（空间与节拍，丢了全乱）
② 动作因果链（蓄力 → 触发 → 轨迹 → 对手反应 → 结果）
③ 打击感五件套中的「位移 + 二次破坏」（冲击力主载体）
④ 场机位与运动动词
⑤ 特效细节
⑥ 同期声（留 3~5 条即可）
⑦ 风格形容词（全局锁已声明， Shot 内可省略）
```

### 5.4 禁用清单

```
× 一镜内两个独立事件（掷出 → 命中分两镜）
× 用感受词代替镜头词（「画面很燃」「运镜很炸」）
× 写场景层未预声明的破坏（先声明能碎，才允许碎）
× 特效行写情绪或剧情
× 同一镜内两处黑白闪
× 直接在 Shot 正文写过程备注、队内备注、路径引用
× 为省字删：时长数值 / 位移描述 / 反作用力 / 一整组完整的打击反馈
```
