请对下面这份 Seedance 分镜提示词做「节拍与镜数」自检。你只做检查与修正，不要重写剧情、不要改镜头语言、不要改台词。

一、逐镜提取
按 `====` 分隔逐个 Shot，提取：Shot 编号、镜长（由标题行 `Shot NN｜MM:SS.s-MM:SS.s（X 秒）` 得出），以及「拍摄内容」里**全部时间标记**（形如 `0.0-0.5s`、`0.5-1.5s`、`1.5-5.0s`，按出现顺序记录）。

二、判定（任一条不满足即为违规）
1. 镜数是否落在预算区间：镜数 ≈ 总时长 ÷ 2.0，允许 ±2。15s → 6–9 镜；30s → 13–17 镜；60s → 25–35 镜。超出即「切太碎」。
2. 单镜目标时长是否 ≥1.5s。低于 1.5s 的必须并入相邻镜，不许保留。
3. Σ 各镜镜长是否 = 目标总时长（±0.5s 以内）；各镜标题行时间段是否**首尾相接**（上一镜止点 = 下一镜起点）。
4. 每镜是否都有标题行时间段可解析；有没有哪一镜还挂着末尾的「时长：」旧标签（有就把它并进标题行）。
5. **时间标记是否是穿插在描述句流里的**——「拍摄内容」应当是一段按时间轴推进的连续描述：机位/光照起句（恒定信息不挂时间），随后各时刻发生什么就地写，站位/表情/台词挂在对应时刻上。**如果写成 `时序 0.0-0.5s …；0.5-1.5s …；1.5-5.0s 完全静止…。｜（后面才接机位/光照/表情）` 这种「节拍块 + 描述块」两块拼接，即违规**，必须改写成穿插式；**「时序」二字也不应出现**。
6. 时间标记的秒数是否全为 0.5 的整数倍。**出现 0.15s、0.45s、0.6s、0.8s 这类一律违规**——视频生成模型没有亚秒级时间分辨率。
7. 时间标记是否**按时间顺序出现、从 0.0s 起、首尾相接、中间无缝隙**（跳序也算违规）。
8. **动作完成点 X + 其后静止 Y 是否 = 生成档位总长（5s 档即 5.0）**，即末段止点是否写成了 `X-5.0s`。只写「保持到片段末尾」而没给末段止点，即违规。
9. 起幅（第一个时间标记的止点）是否 ≥0.3s；收势是否 ≥0.3s。收势长度 = **镜长 − 动作完成点 X**（这个值不用写在提示词里，但必须 ≥0.3s）。
10. 动作段是否带了「一气呵成做完即停 / 完成即停」这类词。**缺了即违规**——只写区间不给完成点，模型会把动作铺满整个窗口。
11. 末段是否写了「画面完全静止、无任何运动，持续到最后一帧 / holds still for the final frames」。
12. 是否存在连续 3 镜以上「镜头」字段 + 动作都同构（机位相同、动作相同、只换环境元素）。有就必须合并成 1–2 镜，用「元素在一镜内递变 + 速度力度递变」表达推进。
13. 「拍摄内容」里是否逐镜复述了全局负面约束（无第四人 / 禁止第一人称 / 无多余人物 / 纯音效无 BGM）。复述 3 镜以上即违规——这类约束只在全局锁写一次。

三、输出格式
先给一张表：镜号 / 镜长 / 起幅 / 动作完成点 X / 收势（镜长−X）/ 静止 Y / 判定。
再逐条列出违规项，每条写清「哪一镜、哪里错、怎么改」。
最后按下面的顺序给出修正后的完整提示词（可复制区，零备注零元信息）。

四、修正规则（不许违反）
- 节拍写成了 `时序 …｜…` 两块拼接 → 改写成穿插式：机位/光照起句，时间标记按时间顺序揉进描述句流，站位/表情/台词挂到对应时刻上，删掉「时序」二字与 `｜`。
- 镜太碎 → 合并相邻镜，**优先合并同构镜**；合并后每镜仍只做 1 个主动作（1.5–2.5s）或 ≤2 个（2.5–4s）。
- 秒数不是 0.5 倍数 → 就近取 0.5 的倍数，并同步调整 X、末段止点，使末段止点仍 = 5.0。
- 收势不足 0.3s → 加大镜长或减小 X（即让动作早点完成）。
- 缺「做完即停」→ 在动作段补上；缺「静止到最后一帧」→ 在末段补上，中英并列。
- 正文复述了全局约束 → 删掉，只在全局锁保留一次。

五、绝对不许为了通过检查而删掉的内容
表情三维度（眼部 / 嘴角 / 面部）、机位数值、景深与焦点、环境光照、台词与弹窗原文、资产锚定描述。压不动就合并镜头，不许删这些。
