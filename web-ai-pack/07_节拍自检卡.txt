请对下面这份 Seedance 分镜提示词做「节拍与镜数」自检。你只做检查与修正，不要重写剧情、不要改镜头语言、不要改台词。

一、逐镜提取
按 `====` 分隔逐个 Shot，提取：Shot 编号、镜长（由「时长：MM:SS.s-MM:SS.s 秒」相减得出）、节奏行里的三个秒数（起幅 a / 动作完成点 X / 静止时长 Y）。

二、判定（任一条不满足即为违规）
1. 镜数是否落在预算区间：镜数 ≈ 总时长 ÷ 2.0，允许 ±2。15s → 6–9 镜；30s → 13–17 镜；60s → 25–35 镜。超出即「切太碎」。
2. 单镜目标时长是否 ≥1.5s。低于 1.5s 的必须并入相邻镜，不许保留。
3. Σ 各镜镜长是否 = 目标总时长（±0.5s 以内）。
4. 节奏行里写出的秒数（起幅 / X / Y）是否全为 0.5 的整数倍。**出现 0.15s、0.45s、0.6s、0.8s 这类一律违规**——视频生成模型没有亚秒级时间分辨率。
5. 动作完成点 X + 静止时长 Y 是否 = 5（5s 档）。
6. 起幅 a 是否 ≥0.3s；收势是否 ≥0.3s。收势长度 = 镜长 − X（这个值不用写在提示词里，但必须 ≥0.3s）。
7. 每个节奏行的收势段是否写了「画面静止持续到最后一帧 / holds still for the final frames」。
8. 是否存在连续 3 镜以上「镜头」字段同构（机位相同、动作相同、只换环境元素）。有就必须合并成 1–2 镜，用「元素在一镜内递变 + 速度力度递变」表达推进。
9. 「拍摄内容」里是否逐镜复述了全局负面约束（无第四人 / 禁止第一人称 / 无多余人物 / 纯音效无 BGM）。复述 3 镜以上即违规——这类约束只在全局锁写一次。

先给一张表：镜号 / 镜长 / 起幅 / 动作完成点 X / 收势（镜长−X）/ 静止时长 Y / 判定。
再逐条列出违规项，每条写清「哪一镜、哪里错、怎么改」。

四、修正规则（不许违反）
- 镜太碎 → 合并相邻镜，**优先合并同构镜**；合并后每镜仍只做 1 个主动作（1.5–2.5s）或 ≤2 个（2.5–4s）。
- 秒数不是 0.5 倍数 → 就近取 0.5 的倍数，并同步调整 X、Y 使 X + Y = 5。
- 收势不足 0.3s → 加大镜长或减小 X（即让动作早点完成）。
- 缺「静止持续到最后一帧」→ 补上，中英并列。
- 正文复述了全局约束 → 删掉，只在全局锁保留一次。

五、绝对不许为了通过检查而删掉的内容
表情三维度（眼部 / 嘴角 / 面部）、机位数值、景深与焦点、环境光照、台词与弹窗原文、资产锚定描述。压不动就合并镜头，不许删这些。
