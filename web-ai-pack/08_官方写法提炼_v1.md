# Seedance 2.0 官方提示词写法提炼

> 来源：官方《即梦 Seedance 2.0 使用手册》全文（1002 段，含 40+ 条官方 Case 提示词原文）
> 整理日期：2026-09-28
> 用途：**这是提示词写法的第一真源**。本文与旧规范冲突时，一律以本文为准。

---

## 零、三条推翻我们旧设计的硬事实

| # | 官方原文 | 我们之前的理解 | 后果 |
|---|---|---|---|
| 1 | **「生成时长 ≤ 15s，可自由选择 4-15s」** | 以为只有 5s / 10s 两个死档 | 整套「按 5 秒档生成、只取前 X 秒」「X + Y = 5」的设计**全部作废**。想要 4 秒就选 4 秒，不用生成 5 秒再裁 |
| 2 | **官方提示词是一段自然语言，没有字段、没有标签** | 我们写了「镜头：/ 拍摄内容：/ 同期声：」三字段 + 机位数值 + 景深焦点 + 光照五要素 | 我们的字段是给人看的表格，模型要的是一段通顺的话 |
| 3 | **一条 prompt 就能出 15 秒、内含 4-5 个分镜**，靠「0-3秒画面：… 3-6秒画面：…」写时间线 | 我们一镜一条 prompt | 快切不用生成很多条，**写在一条里用「快速闪切」「切镜」表达**即可 |

## 一、官方提示词的真实长相（原文照抄）

### 例 1 · 最标准的「编辑 + 故事线」结构（15s）

```
将视频@视频1中的小猫作为主体1，将@视频1中给小猫洗澡的主人作为主体2。
主体2给主体1洗澡，主体1对洗澡从适应到主动喜欢，呈现轻松愉悦的洗澡全过程，
穿插主体1舒适享受的特写画面，替换原视频中害怕、震惊的神态，贴合原视频洗澡画面与特写穿插的剪辑逻辑。
具体故事线：0-5秒，先呈现主体1靠近水盆时的好奇试探（情绪：好奇、放松）。6-11秒，再展示洗澡时主体2给
主体1涂抹沐浴露，主体1被温水冲洗、揉搓毛发的画面（情绪：惬意、享受），穿插主体1眯眼、蹭洗澡工具的
特写（情绪：温顺、欢喜）。12-15秒，最后呈现主体1洗完澡后甩毛、舔毛的舒适画面（情绪：满足、慵懒）。
整体画面色调柔和，节奏舒缓，搭配轻快治愈的背景音乐，全程突出小猫喜欢洗澡的状态，无任何害怕、震惊的
表情和动作，与原视频画面穿插逻辑保持一致，让修改后的视频自然流畅、治愈吸睛。
```

### 例 2 · 多图 + 参考视频（15s）

```
将@图片1的红衣女将军作为主体1、主体1的武器为@图片3主体3，@图片2的蓝衣女将军作为主体2，
主体2的武器为@图片4主体4。
参考@视频1中两个女生打戏的灵动飘逸、刚柔并济风格，制作两位女将军对战的相同动作、相同质感视频。
故事线为：0-2秒，主体1挥动主体3，击打主体2，主体2被弹开、落入下风，具体参考@视频1。3-12秒，
接着展示两人正式交锋的打戏画面具体参考@视频1，主体1使用主体3，主体2使用主体4，主体1（情绪：专注、
桀骜）、主体2（情绪：不甘、奋进）。13-15秒，主体1再次击打开主体2，主体2落入下风，具体参考@视频1。
整体画面色调偏古风氛围感，光影细腻柔和，节奏张弛有度，搭配古风激昂又有韵律的背景音乐，镜头切换流畅，
突出主体1与主体2的辨识度，让视频自然流畅、吸睛有质感。
```

### 例 3 · 快节奏分镜写法（15s 五段，含快切）

```
颠覆@视频1的整个剧情
0–3秒画面：西装男坐在酒吧，神情冷静，手里轻晃酒杯。镜头缓慢推进，光影高级、氛围严肃。环境音低沉，
西装男小声说"这单生意，很大。"
3–6秒画面：身后的女人表情紧张问"有多大？"西装男抬眼，压低声音："非常大。"镜头切手部特写——他把
酒杯放下，气场拉满。
6–9秒画面：突然西装男从桌下掏出—— 一大包体积夸张的零食礼包，"咚"的一声重重放在桌上。
9–12秒画面：身后的女人原本放在腰间的手，肌肉从僵硬到松弛，整个人表情放松。画面氛围轻松起来。
13–15秒画面：西装男拿出一包零食给女人，镜头拉远展示酒馆全景，画面变得透明模糊——字幕弹出"再忙，
也要记得吃点零食~"
```

### 例 4 ·「快速闪切」就是这么写的（15s 电商）

```
0-2秒画面：快速四格闪切，红、粉、紫、豹纹四款蝴蝶结依次定格，特写缎面光泽与 "chéri" 品牌字样。
画外音"Chéri 자석 리본으로 무궁무진한 아름다움을 연출해 보세요!"
3-6秒画面：特写银色磁吸扣 "咔嗒" 吸合，再轻轻一拉分开，展示丝滑质感与便捷性。画外音"단 1초 만에
잠그고, 최고의 스타일을 완성하세요!"
7-12秒画面：快速切换佩戴场景：酒红款别在大衣领口，通勤氛围感拉满；粉色款绑在马尾，甜妹出街；紫色款
系在包带，小众高级；豹纹款挂在西装领，辣妹气场全开。画外音"…"
13-15秒画面：四款蝴蝶结并排陈列，品牌名 "chéri, 당신에게 즉각적인 아름다움을 선사합니다!"
```

> **快节奏不用多生成几条**——「快速四格闪切」「快速切换」「依次定格」这些词写进一条里就行。

## 二、官方写法六要素（记住这个就够了）

### 1. 主体锚定：用 `@素材名` + 「主体1/主体2」
- `@图片1的红衣女将军作为主体1`、`@视频1中的小猫作为主体1`、`@图片3主体3`（武器/物件也算主体）
- 官方**不用角色名**，全用「主体1 / 主体2」编号，并在后面一直用编号指代
- 官方明确提醒：**「素材多的时候，建议你多检查一下各个 @对象有没有标清楚，别把图、视频、角色搞混了哦」**

### 2. 时间线：`<起>-<止>秒画面：` — **整数秒，1 秒粒度**
- 官方全部用整数：`0-5秒`、`6-11秒`、`12-15秒`、`0-3秒`、`13-15秒`
- 前缀有两种：`具体故事线：` / `故事线为：` / 直接 `0-3秒画面：`
- **最短的一段是 1 秒**（`3-4秒`、`13-14秒`），没有见过 0.5 秒的段
- **段与段首尾相接**，覆盖到总时长最后一秒
- 连接词固定几套：`先呈现… → 再展示… → 最后呈现…`；`0-2秒… 3-12秒… 13-15秒…`

### 3. 每段里塞四样东西，都是自然语言混着写
| 要素 | 官方写法举例 |
|---|---|
| 景别 / 运镜 | `切镜，特写` / `镜头跟随在他身后` / `侧面固定镜头` / `镜头缓慢推进` / `俯拍` / `一镜到底` / `镜头小幅度拉远（露出街头全景）并跟随女主移动` / `急停后右摇180度，怼脸拍摄主角正面` |
| 动作 | `用力抖一抖衣服` / `双手死命推搡` / `从桌下掏出一大包零食礼包，"咚"的一声重重放在桌上` |
| 情绪 | 用括号标注：`（情绪：好奇、放松）` `（情绪：惬意、享受）` `（情绪：委屈又呆萌）` |
| 台词 | 直接写进句子，中文引号：`用四川口音点单："幺妹儿，霸王别姬有得没得？"` |

### 4. 整体收尾句：一段话打包「色调 / 光影 / 节奏 / 音乐 / 排除项」
官方几乎每条都有，句式高度一致：
```
整体画面色调柔和，节奏舒缓，搭配轻快治愈的背景音乐，全程突出小猫喜欢洗澡的状态，
无任何害怕、震惊的表情和动作，让修改后的视频自然流畅、治愈吸睛。
```
```
整体画面色调偏古风氛围感，光影细腻柔和，节奏张弛有度，搭配古风激昂又有韵律的背景音乐，
镜头切换流畅，突出主体1与主体2的辨识度，让视频自然流畅、吸睛有质感。
```
**排除项是放在这里、写成一句的**（`无任何…`、`不要出现人物`、`全程不要切镜头`），不是单独一列负面词。

### 5. 声音：一句话带过，不单列
- `背景音恢宏大气` / `搭配轻快治愈的背景音乐` / `背景音效为走路声，人群声，汽车声等等`
- `人群慌乱的声音` / `画外音"…"` / `英文渐显第一行"Lucky Coffee"`
- 画面内的字幕、品牌字也直接写：`字幕弹出"再忙，也要记得吃点零食~"`

### 6. 长度：绝大多数 80–250 字
- 最短 29 字，最长的「小猫洗澡」约 250 字
- **没有任何一条接近 1000 字**。我们之前每镜写 1000 字是严重超配

## 三、官方硬性参数（§1 参数预览）

| 维度 | 限制 |
|---|---|
| 图片输入 | jpeg / png / webp / bmp / tiff / gif，**≤ 9 张**，< 30 MB |
| 视频输入 | mp4 / mov，**≤ 3 个**，总时长 **[2, 15]s**，< 50 MB；总像素 [409600（640×640），927408（834×1112）] |
| 音频输入 | mp3 / wav，**≤ 3 个**，总时长 ≤ 15s，< 15 MB |
| 文本输入 | **自然语言** |
| **生成时长** | **≤ 15s，可自由选择 4-15s** |
| 声音输出 | **自带音效 / 配乐**（不用另外合成） |
| 混合输入 | **总文件数上限 12 个** |

### 两个入口
- **首尾帧入口**：只上传首帧图 + prompt
- **全能参考入口**：图 / 视频 / 音频 / 文本组合输入
- ⚠️ 智能多帧和主体参考**无法选中**

### ⚠️ 写实人脸硬限制（对我们影响很大）
> 「目前暂不支持上传包含**写实真人脸部**的素材（图片和视频素材均不行）…系统会自动拦截此类素材，上传后将无法生成视频内容。」

→ **实拍真人广告（如恐龙烧烤那条）走 Seedance 时，参考图不能用真人正脸照**；要么改用 3D/插画/AI 生成的非写实人脸，要么只上传非人脸素材（场景、商品、背影）。

## 四、官方特殊用法（2.2 节原文）

| 需求 | 官方写法 |
|---|---|
| 有首帧还想参考视频动作 | 「@图1为首帧，参考@视频1的打斗动作」 |
| 延长已有视频 | 「将@视频1延长 5s」— **生成时长要选「新增部分」的时长** |
| 融合多个视频 | 「我要在@视频1和@视频2之间加一个场景，内容为xxx」 |
| 没音频素材 | 直接参考视频里的声音 |
| 连续动作 | 「角色从跳跃直接过渡到翻滚，保持动作连贯流畅」@图1@图2@图3 |

## 五、我们规范的修正清单（旧 → 新）

| 项 | 旧（v3.1 / v3.2） | 新（v4 · 按官方） |
|---|---|---|
| 形态 | 三字段：镜头 / 拍摄内容 / 同期声 | **一段自然语言，不分字段** |
| 长度 | 每镜 700–1100 字 | **每条 150–350 字** |
| 时间线 | 标题行 `Shot 04｜00:04.8-00:06.8（1.6 秒）` + 正文 0.5s 粒度穿插 | **`0-3秒画面：` 整数秒、1 秒粒度** |
| 生成单位 | 一镜一条，5s 档生成再裁 | **一条 = 一次生成，时长 4-15s 自选，一镜到底或多镜快切都写在一条里** |
| 快节奏 | 靠切更多条、单镜 <1.5s | **一条里写「快速闪切 / 切镜 / 依次定格」** |
| 角色指代 | @角色A / @胖子 | **@图片1 的 XX 作为主体1**，后文统一用「主体1」 |
| 情绪 | 表情库三维度双写（眼部/嘴角/面部） | **（情绪：好奇、放松）** — 表情库降级为「需要精细控制时的可选加料」，不再强制 |
| 机位 | 必须数值化（离地 X 米）+ 景深焦点 | **自然语言**：`贴地低角度侧拍` `镜头跟随` `缓慢推近`；数值仅在有参考图对齐需求时补 |
| 光线 | 全局锁「光线：」+ 每镜「环境光照」两处必写 | **并入整体收尾句**：`光影细腻柔和` `夕阳侧逆光体积光穿过尘粒` |
| 声音 | 单列「同期声：」字段 | **并入段落或收尾句**：`背景音效为走路声，人群声` |
| 负面约束 | 全局负面只写一次、禁止逐镜复述 | **并入每条的整体收尾句**（官方就这么写） |
| 静止到末帧 | 每镜强写「画面完全静止持续到最后一帧」 | **删除**。官方无此写法；仅**首尾帧循环视频**需要时保留 |
| 「做完即停」 | 每动作段必写 | **删除**。官方不这么写，节奏靠「节奏舒缓 / 张弛有度 / 急促」 |

## 六、v4 模板（照这个写）

```
将@图片1的<角色>作为主体1，@图片2的<角色>作为主体2，@图片3的<物件>作为主体3。
<一句话讲清这一条要发生什么 / 参考谁：参考@视频1的运镜、整体参考@视频1的节奏>

0-2秒画面：<景别/运镜>，<谁做什么>（情绪：xx）。
2-5秒画面：切镜，<景别/运镜>，<谁做什么>，说："台词"（情绪：xx）。
5-8秒画面：切镜，…

整体画面<色调>、<光影>，节奏<舒缓/急促/张弛有度>，搭配<背景音乐/音效>，
全程突出<核心卖点>，无<要排除的东西>，让视频自然流畅、<想要的观感>。
```

**规矩只有五条**：
1. **整数秒、1 秒粒度、从 0 起、首尾相接**；
2. 角色用 `@图片N` 锚定一次，后面全叫「主体N」；
3. 景别/运镜/动作/情绪/台词**混在句子里写**，不单列；
4. 结尾必有一句「整体…」打包色调 + 光影 + 节奏 + 声音 + 排除项；
5. **全条 150–350 字**，超了就拆成两条（按时间线断开处拆）。
